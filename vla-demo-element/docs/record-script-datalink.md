# 数联标注云 · 录屏操作脚本（DataLink Label）

> 环境：http://127.0.0.1:5101　数据：本地 mock + `public/samples` 脱敏样例  
> 建议分辨率 1920×1080；每个大项可单独成片或按下方顺序一镜到底。  
> 顶栏随时可点 **操作日志** 展示审计时间线；角色切换用于权限演示。

---

## 片头（15s）

1. 打开工作台 `/`，展示产品名「数联标注云 / DataLink Label」、待办工单表。  
2. 指一下侧栏四大模块：质控中心 / 智能预标 / 具身采集标注 / 算法工场。  
3. 顶栏切换身份：**管理员**（后续训练与分配需要）。

---

## 一、多模态数据标注与质量控制（约 4–6 min）

### 1.1 五模态标注（1.5 分）

1. 进入 **质控中心** → 工单列表。  
2. 打开「客服工单实体抽取返修」→ **标注工作台**：展示文本高亮实体。  
3. 返回列表，打开「桌面抓取语义分割」：右侧标签，中间 **真实桌面静帧** + 分割色块。  
4. 打开「指令语音切片」：波形图 + **可播放 wav** + 切片条。  
5. 打开「料箱分拣视频目标检测」：播放 **bin_pick.mp4**，叠加检测框。  
6. 打开「桌面点云分割」：点云示意图 + 类别点数表。  
7. 点「保存标注」，等待进度条，再看顶栏 **操作日志**。

### 1.2 任务协作闭环（1.5 分）

1. **协作看板** `/qc/workflow`：拖览各状态列（已创建→分配→标注中→初审→终审→完成/驳回）。  
2. 选一张卡查看批注与历史。  
3. 进入 **多级审核** `/qc/audit`：以审核员做初审通过 / 驳回（填原因）；管理员做终审。  
4. 对被驳回工单走返修再提交，强调闭环。

### 1.3 抽检与回流（1 分）

1. **标注规范** `/qc/spec`：滚动展示规范章节。  
2. **抽检回流** `/qc/sample-check`：编辑/启用抽检规则 → 执行随机抽检。  
3. 对样本点「合格通过」与「不合格驳回」；合格项执行 **回流**。  
4. 再开操作日志确认审计条目。

---

## 二、自动化预标注（约 3–4 min）

### 2.1 文本预标（1.5 分）

1. **智能预标 → 文本预标**。  
2. 选文档，展示分类 / 实体 / 关系 / 结构化 JSON。  
3. 修正故意错误（如 ADDRESS 被标成 ORG、关系类型错误）→ 保存人工结果。

### 2.2 OCR + YOLO（1 分）

1. **视觉预标**：展示桌面/料箱真实图片。  
2. 对照 OCR 与 YOLO 结果，改错字/错类别 → 保存。

### 2.3 验收向导（1.5 分）

1. **验收向导**：按步进走完 确认 → 标注复核 → 质量检查 → 验收通过。  
2. 展示每步状态与最终验收结果。

---

## 三、VLA 智能数据采集与标注（约 5–7 min）

### 3.1 采集配置（2.5 分）

1. **具身采集 → 采集配置**。  
2. 故意留空点提交，展示 **红色表单校验**。  
3. 填齐：任务名称、场景、方案、模式、动作模板（多选）、人员 → 创建成功，跳转时间轴。

### 3.2 联动标注与三格式导出（3 分）

1. **时间轴标注**：上方任务信息与指令；中间播放真实 mp4；下方动作列表。  
2. 拖动帧滑条，高亮当前动作；编辑起止帧 / 关键节点 / 指令说明并保存。  
3. 点导出：依次下载 **JSON、Excel、CSV**（浏览器真实下载）。

### 3.3 样本质检过滤（2.5 分）

1. **样本质检**：运行检测，展示抖动、遮挡、模糊、缺失、不匹配。  
2. 标记不合格样本并执行过滤；列表仅保留合格样本。

---

## 四、算法训练与验证（约 3–4 min）

### 4.1 配置与 GPU（2 分）

1. 确认角色为 **管理员**。  
2. **算法工场 → 实验配置**：选算法/版本/模型，填 batch/lr/epochs，勾选增强与 GPU。  
3. 创建实验 → 再在分配面板绑定 GPU 卡名。  
4. 可切换为标注员演示按钮禁用 / 提示无权限。

### 4.2 运行与指标报表（2 分）

1. **训练运行**：Start，观察进度、日志、增强状态；可 Stop。  
2. **训练指标**：loss / acc / mAP 三曲线 + 表格。  
3. 导出报表 CSV / Excel。

---

## 片尾（10s）

1. 回到工作台，快速扫一眼操作日志。  
2. 口播：以上均在真实可运行前端 + 脱敏样例下完成，覆盖评分表全部能力点。

## 录制注意

- 语音切片务必点播放，视频务必点播放，避免仍像静态占位。  
- 导出动作要露出下载文件名。  
- 驳回、校验失败、权限拒绝各至少出镜一次，体现「真实系统」而非纯 happy path。
