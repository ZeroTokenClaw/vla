# 数联标注云 DataLink Label（vla-demo-element）

Vue3 + Vite + Element Plus 演示前端，端口 **5101**。  
定位：企业蓝灰「工单流」厂商产品，覆盖全部评分点，本地 mock + 脱敏样例数据。

## 启动

```bash
cd E:\omp\vla\vla-demo-element
pnpm install
pnpm dev
```

浏览器：http://127.0.0.1:5101

顶栏可切换 **标注员 / 审核员 / 管理员**，并打开 **操作日志**（审计抽屉，全模块通用）。

## 模块路由

| 路径 | 模块 |
|------|------|
| `/` | 工作台（KPI 驾驶舱 + 待办跳转） |
| `/qc` | 质控中心 |
| `/qc/annotate/:id?` | 多模态标注工作台 |
| `/qc/workflow` | 协作看板（分配/流转/批注） |
| `/qc/audit/:id?` | 多级审核（驳回返修闭环） |
| `/qc/sample-check` | 抽检规则 / 随机抽检 / 回流 |
| `/qc/spec` | 标注规范 |
| `/prelabel/text` | 文本分类·NER·关系·结构化 + 模型选择 + 人工修正 |
| `/prelabel/vision` | OCR + YOLO 预标（可选模型/阈值）+ 人工修正 |
| `/prelabel/accept` | 确认·标注·质检·验收向导 |
| `/prelabel/jobs` | 批量预标任务队列 · 进度 · 失败重试 · Diff 统计 |
| `/vla/collect` | 采集任务/场景/方案/模式/模板/人员/设备/进度 |
| `/vla/devices` | 采集设备台账与绑定任务 |
| `/vla/timeline/:id?` | 多模态联动·动作序列·关键节点·起止帧·导出 |
| `/vla/quality/:id?` | 抖动/遮挡/模糊/缺失/不匹配 · 检测版本 · 标记过滤 |
| `/train/config` | 算法/版本/模型/数据集版本/参数/GPU |
| `/train/runner/:id?` | 启动/暂停/恢复/停止/重试 · 数据增强 |
| `/train/metrics/:id?` | loss / acc / mAP · 报表导出 |
| `/train/gpus` | GPU 利用率/显存/温度监控（演示伪造读数） |

## 评分点 → 菜单路径 → 演示要点

| 评分项 | 分值 | 菜单路径 | 演示要点 |
|--------|------|----------|----------|
| 1.(1) 多模态能力 | 1.5 | 质控中心 → 标注工作台 | 切换文本NER / 图像分割 / 语音切片 / 视频检测 / 点云分割；可见真实样例图/视频/波形/点云预览 |
| 1.(2) 任务协作闭环 | 1.5 | 工单列表 → 协作看板 → 多级审核 | 创建/分配、状态流转、多人协作批注、驳回返修、初审/终审 |
| 1.(3) 抽检回流 | 1.0 | 抽检回流 + 标注规范 | 规则配置、随机抽检、合格通过/不合格驳回、合格回流 |
| 2.(1) 文本预标 | 1.5 | 智能预标 → 文本预标 | 分类、实体、关系、结构化结果；对照修正故意错误项 |
| 2.(2) 视觉预标 | 1.0 | 智能预标 → 视觉预标 | OCR + YOLO 框；人工改标签/框后保存 |
| 2.(3) 验收全流程 | 1.5 | 智能预标 → 验收向导 | 确认 → 标注 → 质检 → 验收步进 |
| 3.(1) 采集配置 | 2.5 | 具身采集 → 采集配置 | 任务名、场景、方案、模式、动作模板、人员；表单必填校验 |
| 3.(2) 标注与导出 | 3.0 | 时间轴标注 | 视频/图像/指令联动；动作序列与关键节点；导出 JSON/Excel/CSV |
| 3.(3) 样本质检 | 2.5 | 样本质检 | 检测五类问题；标记不合格并过滤 |
| 4.(1) 训练配置 | 2.0 | 算法工场 → 实验配置 | 算法/版本/模型/超参、创建实验、GPU 分配（需管理员） |
| 4.(2) 运行与指标 | 2.0 | 训练运行 + 训练指标 | 启停、增强、loss/acc/mAP 曲线、导出报表 |
