# 《现有系统功能盘点报告》

> 产品：数联标注云 DataLink Label（`vla-demo-element`）  
> 分析日期：2026-11-09  
> 范围：仅本套 Element Plus 演示前端；不覆盖 antd/naive/arco 三套分叉  
> 结论先行：**16 分评分点在「可操作演示闭环」层面已基本齐备；按招标提示词「真实后端 / 真实算法 / 持久化 / 非模拟指标」标准，整体仍属演示级，工程真实性存在系统性缺口。**

---

## 1. 系统定位与技术栈

| 项 | 现状 |
|----|------|
| 定位 | 招标演示前端：本地 mock + 脱敏样例，**无独立后端服务** |
| 技术栈 | Vue3 + Vite + Element Plus + Pinia + ECharts + xlsx + Vitest |
| 端口 | `5101` |
| 数据层 | `src/mock/*` 内存种子 + `src/services/*` 延迟封装（`businessDelay`） |
| 审计 | `stores/audit.js` 内存操作日志抽屉 |
| 权限 | 顶栏三角色切换：标注员 / 审核员 / 管理员（非登录鉴权） |
| 媒体 | `public/samples/` 真实短视频/图片/音频；点云为预览图 |

设计文档明确非目标：真实模型服务 / 真实 GPU 集群 / monorepo 共享包。


## 3. 四大模块能力盘点

### 3.1 多模态数据标注与质量控制

| 能力 | 实现形态 | 证据 | 判定 |
|------|----------|------|------|
| 文本 NER | 工作台高亮实体 + 增删改 + 保存 | `AnnotateWorkbench.vue` + `SAMPLE_RESOURCES.text_ner` | 演示已实现 |
| 图像语义分割 | 静帧 + mask 列表（非多边形画布引擎） | `masks` 色块展示 | **部分实现**（无真实多边形绘制） |
| 语音切片 | wav 可播 + 切片条编辑 | `audio_slice` | 演示已实现 |
| 视频目标检测 | mp4 播放 + 检测框列表 | `video_det` | **部分实现**（无逐帧画框/跨帧跟踪 UI） |
| 点云分割 | 预览图 + 类别点数表 | `point_seg` | **部分实现**（无三维交互选点） |
| 任务 CRUD/分配/流转 | 状态机 `TRANSITIONS` + 权限校验 | `qc.js` | 演示已实现 |
| 批注/历史/驳回返修 | comments / history / rejectChain | 看板+审核页 | 演示已实现 |
| 多级审核 | 初审 `reviewing` → 终审 `final_review` | 标注员不可终审 | 演示已实现 |
| 抽检规则/随机抽检/回流 | `runSampleCheck` / `refluxPass` | `SampleCheck.vue` | 演示已实现 |
| 标注规范 | 静态章节 `SPEC_SECTIONS` | `SpecDoc.vue` | 演示已实现 |
| 持久化 / 多用户并发 | 刷新即丢失内存态 | — | **未实现** |

### 3.2 AI 自动化预标注

| 能力 | 实现形态 | 判定 |
|------|----------|------|
| 文本分类/NER/关系/结构化 | 预置 model 结果 + 人工 Diff 修正 | 演示已实现（**非真实 NLP/LLM 推理**） |
| OCR / YOLO | 预置框与文字 + 可改保存 | 演示已实现（**非真实模型调用**） |
| 验收向导 | confirm → annotate → qa → accept | 演示已实现 |
| 模型选择与参数配置 | 无独立模型服务配置页 | **未实现** |
| 批量预标注任务队列/失败重试 | 单文档 run*，无任务调度器 | **未实现 / 弱实现** |
| 预标 vs 人工结果对比统计 | Diff 修正日志有，缺量化对比报表 | **部分实现** |

### 3.3 VLA 智能数据采集与标注

| 能力 | 实现形态 | 判定 |
|------|----------|------|
| 采集任务创建（场景/方案/模式/模板/人员） | 表单校验 + `createCollectTask` | 演示已实现 |
| 设备配置与设备关联 | 无设备实体 | **未实现** |
| 时间轴联动标注 | 视频+指令+动作片段+关键节点+起止帧 | 演示已实现 |
| JSON/Excel/CSV 导出 | `exportVla` 真实浏览器下载 | **已实现（文件真实生成）** |
| 五类质量检测 | `detectIssues` 返回种子/模板问题 | 演示闭环有（**非视觉算法检测**） |
| 标记不合格 / 过滤 | `markUnqualified` / `setFilterUnqualified` | 演示已实现 |
| 轨迹 JSON（joints/gripper） | episode 详情含 trajectory | 演示数据已有 |

### 3.4 算法训练与验证

| 能力 | 实现形态 | 判定 |
|------|----------|------|
| 算法/版本/模型/超参/GPU 分配 | `AlgoConfig.vue` + 管理员权限 | 演示已实现 |
| 启停 / 数据增强 | `startTrain` / `stopTrain` / augmentOps | 演示已实现 |
| loss/acc/mAP | `tickEpoch` → `mockMetricPoint` 生成 | **模拟指标（招标真实性不达标）** |
| 报表导出 | CSV/Excel 真实下载 | 演示已实现 |
| 真实训练进程 / GPU 监控 | 无 Worker / 无 NVML | **未实现** |
| Checkpoint 落盘 | 仅路径字符串展示 | **未实现** |

## 4. 已有「像真系统」零件（可保留复用）

1. 状态机与角色权限拒绝（工单流转、训练创建/启停）。  
2. 操作审计抽屉（全模块 `pushAudit`）。  
3. ≥50 条厚数据 + 分页筛选（QC / 预标 / VLA / 训练）。  
4. 表单校验失败态、进度条/延迟中间态。  
5. 真实媒体播放与三格式导出工具 `exportFiles.js`。  
6. Vitest：流转、列表、导出、seed 规模等冒烟用例。

---

## 5. 关键风险与边界

| 风险 | 说明 |
|------|------|
| 评委追问「算法是否真实」 | 预标/质检/训练指标均可被识破为 mock |
| 刷新丢数据 | 无 DB；演示需同一会话内完成 |
| 点云/分割/视频画框深度不足 | 展示型工作台，缺专业标注引擎 |
| 与提示词冲突 | 提示词禁止「仅模拟」；当前仓库目标即为演示 mock |

---

## 6. 盘点结论

- **演示验收路径**：按 `docs/record-script-datalink.md` 可覆盖 16 分点操作演示。  
- **工程验收路径**：需新增后端、持久化、真实/半真实算法服务与训练 Job Runner，见《06-功能缺口及研发实施计划》。  
- **复用策略**：保留现有路由 IA、服务 API 形状、状态枚举与导出工具；将 `services/*` 从内存实现替换为 HTTP 客户端，是成本最低的升级路径。
