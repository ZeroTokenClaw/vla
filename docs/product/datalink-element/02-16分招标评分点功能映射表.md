## 6. 评分风险提示（对内）

1. **最高风险**：4.2 训练指标与 2.x/3.3 算法能力被追问「是否真实推理」。  
2. **中风险**：1.1 点云/分割/视频深度不够「专业标注工具」观感。  
3. **低风险**：导出、流转、角色权限、审计——演示说服力较强。  
4. 若招标现场按提示词严格验「非模拟」，需优先落地《06》P0：训练日志真实化 + 至少一路真实/半真实推理服务。
