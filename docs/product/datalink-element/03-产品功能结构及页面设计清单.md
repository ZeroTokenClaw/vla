## 3. 页面级设计（输入 / 处理 / 输出）

### 3.1 质控 · 工单列表 `/qc`

| 项 | 内容 |
|----|------|
| 输入 | 筛选：状态/模态/优先级/关键词；分页 |
| 处理 | `listQcTasks`；创建 `createQcTask`；分配 `assignTask` |
| 输出 | ≥50 工单表；跳转工作台/审核 |
| 现状 | 已有 |
| 升级 | 软删除；工作量统计列（doneCount/sampleCount）图表 |

### 3.2 质控 · 标注工作台 `/qc/annotate/:id`

| 模态 | 画布区 | 右侧面板 | 升级交互 |
|------|--------|----------|----------|
| 文本 | 原文 + 实体高亮 | 类型/起止/关系 | 拖选建实体；关系边编辑 |
| 图像分割 | 图片 | 类别/面积/置信度 | 多边形工具；导出 mask PNG |
| 语音 | 波形+audio | 切片起止/转写 | 拖拽改切片边界 |
| 视频 | video+帧滑条 | 检测框表 | 当前帧画框；track_id |
| 点云 | 2D 预览（现状） | 分割类别 | 3D 视图+套索 |

公共操作：保存标注、提交初审、查看历史批注。

### 3.3 质控 · 协作看板 `/qc/workflow`

- 列：按 `STATUS_FLOW`  
- 卡：标题、模态、优先级、负责人  
- 操作：查看批注线程、推进状态（受权限约束）  
- 升级：拖拽改状态（仍走 `transition` 校验）

### 3.4 质控 · 多级审核 `/qc/audit`

- 输入：工单、审核意见、驳回原因码  
- 处理：`transition(..., 'final_review'|'done'|'rejected')`  
- 输出：history + rejectChain  
- 升级：多级配置（可配置审核级数）

### 3.5 质控 · 抽检回流 `/qc/sample-check`

- 规则：比例、模态范围、启用开关、**质量阈值**（升级字段）  
- 动作：随机抽检 / **指定样本 ID 抽检**（升级）  
- 结果：pass / fail+原因 / reflux → Dataset  

### 3.6 预标 · 文本/视觉/验收

| 页 | 主流程 |
|----|--------|
| 文本 | 选文档 → 跑管线 → 四块结果 → Diff 修正 → 保存 |
| 视觉 | 选图 → OCR/YOLO → 改字改框 → 保存 |
| 验收 | Steps：确认→标注复核→质检→验收 |
| 任务队列【新】 | 批量选样本 → 选 Model+参数 → 进度/失败重试 |

### 3.7 VLA · 采集配置 `/vla/collect`

表单字段（现状已有）：名称、场景、方案、模式、动作模板多选、人员多选、指令。  
升级字段：设备 ID 多选、目标采集数量、质量要求文案、数据类型（video/image/action/sync）。

### 3.8 VLA · 设备台账【新】`/vla/devices`

字段：设备编号、类型（相机/麦克风/机械臂/采集工控机）、状态、关联任务数。

### 3.9 VLA · 时间轴 `/vla/timeline/:id`

布局：

```
[任务头：场景/方案/指令]
[视频播放器 + 帧滑条]
[动作序列表：起止帧 | 动作 | 关键节点 | 指令]
[导出：JSON | Excel | CSV]
```

校验：`endFrame > startFrame`；帧范围 ∈ [0, totalFrames]。

### 3.10 VLA · 样本质检 `/vla/quality/:id`

- 运行检测 → 五类 issue 列表 → 标记不合格 → 过滤  
- 升级：展示检测算法版本、人工复核结论、关联帧预览

### 3.11 训练 · 配置 / 运行 / 指标

| 页 | 要点 |
|----|------|
| 配置 | 算法、版本、模型、Epoch/BS/LR、增强、GPU、**数据集版本** |
| 运行 | Start/Stop（升级加 Pause/Resume/Retry）；日志流；进度 |
| 指标 | ECharts loss/acc/mAP；验证表；导出报表 |
| 算力【新】 | 卡利用率、显存、温度（来自 agent） |

## 4. 端到端业务流程

### 4.1 标注闭环

```
创建工单 → 分配 → 标注中 → 保存 → 提交初审
 → 初审通过 → 终审 → 完成
         ↘ 驳回 → 返修(annotating) → 再提交
完成样本 → 抽检 → 合格回流 Dataset
```

### 4.2 预标闭环

```
导入样本 → 选模型 → 创建预标任务 → 推理
 → 人工确认/修正 → 质检 → 验收 → 入库 Dataset
失败 → 重试 / 转人工标注工单
```

### 4.3 VLA 闭环

```
配置场景/方案/设备/人员 → 采集任务
 → 时间轴标注动作序列 → 质检过滤
 → 导出训练包(JSON/CSV/XLSX) → 可选回流 Dataset → 训练实验引用
```

### 4.4 训练闭环

```
选算法/模型/数据集版本 → 配参 → 分配 GPU → 启动
 → 采集真实日志与 metrics → 验证 → Checkpoint → 报表
```
