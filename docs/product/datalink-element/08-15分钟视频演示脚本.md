# 《15分钟视频演示脚本》

> 产品：数联标注云 DataLink Label · http://127.0.0.1:5101  
> 角色建议开场切 **管理员**；审核段切 **审核员**；权限负面例切 **标注员**。  
> 总时长目标：≤15 分钟。详细点击也可对照 `vla-demo-element/docs/record-script-datalink.md`。

---

## 时间盒

| 段 | 时长 | 评分点 |
|----|------|--------|
| 片头 | 0:00–0:20 | 品牌 |
| 质控 | 0:20–4:20 | 1.1–1.3（4 分） |
| 预标 | 4:20–7:00 | 2.1–2.3（4 分） |
| VLA | 7:00–12:00 | 3.1–3.3（8 分） |
| 训练 | 12:00–14:30 | 4.1–4.2（4 分） |
| 片尾 | 14:30–15:00 | 审计收束 |

---

## 0:00 片头（20s）

1. 打开 `/`，露出「数联标注云 / DataLink Label」与待办工单台。  
2. 扫一眼侧栏：质控中心 / 智能预标 / 具身采集标注 / 算法工场。  
3. 口播：「以下为可运行系统 + 脱敏样例，完整覆盖评分表。」  
4. 顶栏切 **管理员**。

---

## 0:20 一、多模态质控（约 4min）

### 1.1 五模态（~2min）

| 时间 | 动作 | 口播要点 |
|------|------|----------|
| | `/qc` 打开「客服工单实体抽取返修」→ 标注工作台 | 文本实体高亮可编辑 |
| | 保存标注，开操作日志 | 结果可追溯 |
| | 回列表进「桌面抓取语义分割」 | 真实静帧 + 分割类别 |
| | 「指令语音切片」点播放 | 可听 wav + 切片 |
| | 「料箱分拣视频」播放 | 真实 mp4 + 检测框数据 |
| | 「桌面点云」 | 预览 + 类别点数（声明预览模式即可） |

### 1.2 协作闭环（~1.2min）

1. `/qc/workflow`：展示各状态列。  
2. `/qc/audit`：切 **审核员** → 驳回并填原因 → 再切管理员终审或展示返修回标注中。  
3. 口播：「创建→分配→标注→初审→终审/驳回返修闭环。」

### 1.3 抽检回流（~50s）

1. `/qc/spec` 快速滚动规范。  
2. `/qc/sample-check`：启用规则 → 随机抽检 → 合格 / 不合格 → **回流**。  
3. 再闪一下操作日志。

---

## 4:20 二、智能预标（约 2.5min）

### 2.1 文本（~1min）

1. `/prelabel/text`，选 `DL-TXT-2026-001`。  
2. 展示分类 / NER / 关系 / 结构化。  
3. 修正故意错误（ADDRESS→ORG 等）→ 保存。

### 2.2 视觉（~50s）

1. `/prelabel/vision`：OCR + YOLO 框叠图。  
2. 改一字或一类 → 保存。

### 2.3 验收（~40s）

1. `/prelabel/accept`：步进 确认→标注→质检→验收。  
2. 展示最终通过态。

---

## 7:00 三、VLA（约 5min）— 分值最高，留足镜头

### 3.1 采集配置（~1.2min）

1. `/vla/collect`：故意空提交 → 红色校验。  
2. 填：名称、场景、方案、模式、动作模板、人员 → 创建成功。

### 3.2 时间轴 + 三导出（~2.5min）

1. `/vla/timeline/DL-VLA-2026-001`（或新建任务）。  
2. 播放视频；拖帧；编辑动作起止与关键节点；保存。  
3. **依次导出 JSON、Excel、CSV**——镜头给到下载文件名（`DL-VLA-...`）。  
4. 可选：展开 trajectory 字段口播「关节/夹爪时间序列」。

### 3.3 质检过滤（~1.3min）

1. `/vla/quality/...`：运行检测。  
2. 指认抖动/遮挡/模糊/缺失/不匹配。  
3. 标记不合格 → 开启过滤 → 列表变化。

---

## 12:00 四、算法工场（约 2.5min）

### 4.1 配置 GPU（~1min）

1. 确认 **管理员**。  
2. `/train/config`：选算法/版本/模型，填 BS/LR/Epochs，勾增强与 GPU → 创建。  
3. 切 **标注员** 点创建 → 展示无权限（负面例 5s）→ 切回管理员。

### 4.2 运行与指标（~1.5min）

1. `/train/runner`：Start → 看日志与进度；可 Stop。  
2. `/train/metrics`：loss / acc / mAP 曲线。  
3. 导出报表 CSV 或 Excel。  
4. **诚实口播（演示模式）**：「指标随实验 epoch 写入并导出；生产环境将对接训练 Worker 日志。」  
   （真实模式则改为：「曲线与服务器 metrics.jsonl 一致。」）

---

## 14:30 片尾（30s）

1. 回 `/`，打开操作日志快速上滑。  
2. 口播收束：「多模态质控、自动预标、VLA 采集标注与导出、训练验证，评分点全覆盖。」  
3. 黑场或停在品牌首页 2s。

---

## 录制检查清单（导演用）

- [ ] 五模态均出镜；音视频真播放  
- [ ] 驳回原因、表单校验、无权限各 ≥1 次  
- [ ] VLA 三格式下载文件名出镜  
- [ ] 训练曲线非空白；导出报表出镜  
- [ ] 操作日志至少打开 2 次  
- [ ] 未口播「假数据/随便点点」等破坏性表述；演示模式用「脱敏样例」表述  

---

## 应急缩时（总时长不够时）

优先保：五模态快切（1.1）→ 驳回闭环（1.2）→ 文本 Diff（2.1）→ VLA 导出三文件（3.2）→ 质检五类（3.3）→ 训练曲线+导出（4.2）。  
可砍：规范页细读、验收逐步念稿、trajectory JSON 展开。
