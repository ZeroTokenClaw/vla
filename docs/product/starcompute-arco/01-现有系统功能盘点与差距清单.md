# 《现有系统功能盘点与差距清单》

> 产品基线：星算训练台 StarCompute（`vla-demo-arco`）  
> 分析日期：2026-11-09  
> 目标：升级为独立「多模态 AI 数据标注与 VLA 智能训练平台」  
> 结论先行：**四大评分模块在演示闭环层面已齐备；按招标「真实后端 / 真实算法 / 持久化 / 可验证结果」标准，整体仍属前端 mock，工程真实性存在系统性缺口。**

---

## 1. 技术栈现状

| 项 | 现状 |
|----|------|
| 定位 | 招标演示前端：本地 mock + 脱敏样例，**无独立后端** |
| 前端 | Vue 3.5 + Vite 8 + Arco Design Vue + Pinia + Vue Router + ECharts + xlsx + Vitest |
| 端口 | `5104` |
| 数据层 | `src/mock/*` 内存种子 + `src/services/*` 延迟封装 |
| 审计 | `stores/audit.js` 内存操作日志 |
| 权限 | 顶栏三角色切换（非登录鉴权） |
| 媒体 | `public/samples/` 真实短视频/图片/音频；点云为预览图 |
| 后端 / DB / Redis / Celery | **不存在** |
| 算法推理服务 | **不存在**（预标/质检/训练均为种子或 PRNG） |

## 2. 模块与路由盘点

| 业务中心 | 路由 | 服务 | Mock |

## 3. 四大模块差距矩阵

### 3.1 多模态数据标注中心（4 分）

| 能力 | 现状判定 | 工程缺口 |
|------|----------|----------|
| 文本实体抽取 | 演示：高亮列表增删改保存 | 缺文本拖选建实体、关系边编辑、落库与导出 API |
| 图像语义分割 | **部分**：mask 列表，无多边形/画笔 | 需真实多边形 + mask PNG/RLE 生成 |
| 语音切片 | 演示：可播 + 切片表 | 缺波形交互裁剪、真实切片文件写出 |
| 视频目标检测 | **部分**：播视频 + 框表 | 缺逐帧画框、跨帧 track_id |
| 点云分割 | **部分**：2D 预览图 | 缺 Three.js/Open3D 三维交互 |
| 任务协作/状态机 | 演示：TRANSITIONS + 批注/多级审核 | 缺 DB 持久化与并发锁 |
| 抽检回流 | 演示：随机抽检闭环 | 缺合格数据回流真实 Dataset |

### 3.2 AI 自动预标注中心（4 分）

| 能力 | 现状判定 | 工程缺口 |
|------|----------|----------|
| 文本分类/NER/关系 | 演示：预置结果 + Diff 修正 | **非真实 NLP 推理** |
| OCR / YOLO | 演示：预置框/文字 | **非真实模型调用** |
| 验收向导 | 演示：四步状态机 | 缺模型结果 vs 人工结果量化对比入库 |
| 批量任务/失败重试 | 弱 | 缺 Celery 任务队列 |

### 3.3 VLA 智能数据采集与标注（8 分）

| 能力 | 现状判定 | 工程缺口 |
|------|----------|----------|
| 采集任务/场景/方案/模板 | 演示表单创建 | 缺设备实体、采集频率/时长完整字段 |
| 多模态联动标注 | 演示：视频+指令+动作+关键节点 | 关联关系仅内存；需统一 sample_id + timestamp |
| JSON/Excel/CSV 导出 | **真实浏览器文件生成** | 需服务端归档 + export_task 记录 |
| 五类质量检测 | 演示：种子 issues | **非视觉算法**（抖动/遮挡/模糊等） |

### 3.4 AI 算法训练与验证（4 分）

| 能力 | 现状判定 | 工程缺口 |
|------|----------|----------|
| 算法/模型/超参/GPU | 演示配置 | 缺真实 GPU 发现与分配 |
| 启停控制 | 演示状态翻转 | 缺真实训练进程 |
| loss/acc/mAP | **`mockMetricPoint` 模拟** | **严重不达标** |
| 报表导出 | 真实 CSV/Excel | 指标来源需改为训练日志 |

## 4. 可复用资产（必须保留）

1. Arco IA、人设、路由结构与评分点菜单映射  
2. `services/*` API 形状（升级为 HTTP 客户端时保持函数签名）  
3. 状态机 `TRANSITIONS`、角色拦截逻辑  
4. `exportFiles.js` 三格式导出  
5. Vitest 冒烟用例与 ≥50 厚数据分页模式  
6. `public/samples/` 脱敏媒体  

**最低成本升级路径**：保留前端壳 → `services/*` 改 HTTP → 新增 `platform/` 后端 + 算法 Worker。

---

## 5. 风险

| 风险 | 影响 | 缓解 |
|------|------|------|
| 评委追问「算法是否真跑」 | 演示失分 | 接通 YOLO/OCR/轻量 NLP；训练写真实 metrics 文件 |
| 无 GPU 环境 | 训练/YOLO 受限 | CPU 跑 yolov8n + 迷你训练 epoch；标注真实日志来源 |
| 点云/分割深度不足 | 1.1 扣分 | 优先上 Three.js 点云 + Canvas 多边形 |
| 刷新丢数据 | 演示中断 | SQLite/PostgreSQL 持久化 |
| 工期过大 | 无法 15 分钟完整演示 | 按评分点优先级切片交付（见 08 研发计划） |
