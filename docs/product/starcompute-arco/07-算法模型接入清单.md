# 《算法模型接入清单》

## 1. 接入原则

1. **算法独立服务/Worker**，禁止在同步 Web 请求内加载重型模型。  
2. 浏览器只提交任务 ID，通过轮询/WS 取进度与结果。  
3. 所有推理结果落库：`model_payload` + `model_version` + `confidence`。  
4. 无 GPU 时允许 CPU 降级；**禁止**用固定假框冒充推理。  
5. 许可证：优先 Apache/MIT/BSD；YOLO AGPL 需在交付说明中披露。

## 2. 模型清单

| 业务 | 模型/库 | 版本建议 | 输入 | 输出 | 降级方案 |
|------|---------|----------|------|------|----------|
| 文本分类 | `transformers` 中文分类或规则+关键词 | 可换 | text | label, conf | 词典规则 |
| NER | spaCy / bert-base-chinese NER | — | text | entities[{start,end,type,conf}] | 正则+词典 |
| 关系抽取 | 规则模板 / 轻量 RE | — | text+entities | relations[] | 共现规则 |
| OCR | PaddleOCR | PP-OCRv4 | image | boxes+text+conf | Tesseract |
| 目标检测 | Ultralytics YOLOv8n | 8.x | image | xyxy, cls, conf | OpenCV Haar（仅兜底演示） |
| 语义分割辅助 | 人工多边形 → mask；可选 SAM | — | image+points | mask PNG/RLE | 仅人工 |
| 语音切片 | FFmpeg + energy VAD | — | audio | slices wav | 手动起止 |
| 视频抽帧 | OpenCV / FFmpeg | — | video | frames | — |
| 抖动检测 | 光流/帧差运动幅度 | OpenCV | video | score+segments | — |
| 模糊检测 | Laplacian 方差 | OpenCV | frame | blur_score | — |
| 遮挡检测 | YOLO 框面积比/缺失 | YOLO+规则 | frame | occlusion_ratio | — |
| 缺失/关联检测 | 结构化规则 | — | meta | missing_fields[] | — |
| 任务不匹配 | CLIP 或文本相似度 | 可选 | image+text | similarity | 关键词规则 |
| 训练 Demo | PyTorch 迷你 CNN/YOLO fine-tune 子集 | — | dataset | metrics 落库 | 必真实写 loss |

## 3. Worker 任务类型

| Celery Task | 触发点 | 产物 |
|-------------|--------|------|
| `nlp.run_pipeline` | 文本预标 Run | preannotation_result |
| `vision.run_ocr` | OCR 按钮 | ocr json |
| `vision.run_yolo` | YOLO 按钮 | detections json |
| `vla.run_quality` | 质检 Run | vla_quality_result[] |
| `train.run_experiment` | 训练 Start | metrics 逐 epoch + weights |
| `export.build_bundle` | 导出 | 文件 path + export_task |

## 4. 版本与可追溯

每次推理写入：

```json
{
  "model_name": "yolov8n",
  "model_version": "8.2.0",
  "weights": "storage/models/yolov8n.pt",
  "params": {"conf": 0.25, "iou": 0.45},
  "device": "cpu",
  "latency_ms": 820
}
```

训练任务绑定 `algorithm_version_id` + `model_version_id` + `dataset_id`。

## 5. 演示环境最小安装

```text
pip install fastapi uvicorn sqlalchemy alembic redis celery
pip install opencv-python-headless pillow numpy
pip install ultralytics paddleocr  # 体积大，可按需
pip install torch --index-url ...  # CPU 版即可
```

若依赖安装失败：启用 `ALGO_MODE=lite`，仍对**真实上传文件**做 OpenCV/规则处理并写真实结果，文档标注能力边界。
