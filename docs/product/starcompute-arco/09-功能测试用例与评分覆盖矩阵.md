## 2. 核心测试用例（摘录）

### TC-A1-文本

1. 导入/打开文本样本 → 拖选「张某」标 PERSON → 保存 → 刷新仍在  
2. 建立实体关系到 ORG → 导出 JSON 含 offsets  

### TC-A1-分割

1. 上传图 → 多边形圈选 → 生成 mask 文件 → 再打开可编辑  

### TC-A2-流转

1. 创建任务 → 分配 → 标注中 → 提交审核 → 驳回 → 返修 → 通过  
2. 标注员终审应 403  

### TC-B2-YOLO

1. 上传真实图片 → Run YOLO → 返回框坐标非种子常量 → 人工改框保存 Diff  

### TC-C2-导出

1. 标注后分别点 JSON/Excel/CSV → 三文件均可打开且 sample_id/timestamp 一致  
2. `export_task` 表有三条记录  

### TC-C3-模糊

1. 上传故意模糊视频 → 质检出 blur 异常 → 标记不合格 → 过滤后入库列表不含  

### TC-D2-指标

1. 启动训练 → `training_metrics` 随 epoch 增加 → 曲线与表一致 → 停止后状态 terminated
