# 《系统产品需求规格说明书》（PRD）

> 产品名称：星算训练台 StarCompute — 多模态 AI 数据标注与 VLA 智能训练平台  
> 版本：V1.0  
> 基线前端：`vla-demo-arco`  
> 工程目录：`platform/`（后端 + 算法服务）

---

## 1. 产品目标

建设可独立运行的专业级平台，支撑招标 **20 分**（文档表述含四大模块合计 20 分，与现演示 16 分评分项对齐扩展）视频演示：

1. 多模态数据真实标注与质量控制  
2. NLP / OCR / YOLO 真实预标注与验收  
3. VLA 多模态联动采集标注与质量检测  
4. 算法训练真实启动并产出可追溯指标  

**非目标（V1）**：公有云多租户计费、完整 MLOps 平台、机器人实机遥操作驱动。

---

## 2. 用户与角色

| 角色 | 职责 |
|------|------|
| 标注员 annotator | 标注、预标修正、VLA 时间轴标注、任务认领 |
| 审核员 reviewer | 审核、抽检、预标验收、VLA 质量复核 |
| 管理员 admin | 项目/数据集/用户、训练启停、GPU 分配、系统配置 |
| 采集员 collector | VLA 采集任务执行（可映射为 annotator 子角色） |

所有状态变更必须记录：操作人、时间、原因。

---

## 3. 功能需求总览

### A. 多模态数据标注中心

- 工作台：左任务列表 / 中画布 / 右标签属性  
- 五模态：文本 NER+关系、图像多边形分割+mask、语音波形切片、视频逐帧检测+track、点云三维分割  
- 任务：创建→分配→标注→多级审核→抽检→回流  
- 状态机（业务文案）：待分配→待标注→标注中→待审核→审核中→已通过；驳回→待返修→重新提交  

### B. AI 自动预标注中心

- 文本：分类 / NER / 关系 → JSON 结构化  
- 图像：OCR + YOLO 真实推理  
- 验收：导入→任务→推理→人工确认修正→质检→入库；保留模型原始结果与人工 Diff  

### C. VLA 智能数据采集与标注中心

- 采集任务 / 场景 / 方案 / 模式 / 动作模板 / 人员 / 设备  
- 联动：视频↔图像帧↔文本↔指令↔动作序列↔关键节点（统一 sample_id + timestamp）  
- 导出：JSON / Excel / CSV 独立下载 + export_task 记录  
- 质检：抖动 / 遮挡 / 模糊 / 缺失 / 不匹配 → 复核 → 过滤 → 入库  

### D. AI 算法训练与验证中心

- 算法/版本/模型/超参/GPU  
- 启停恢复终止重试  
- 数据增强样例预览  
- 真实 metrics：Epoch、Train/Val Loss、Acc、P/R、mAP@口径、LR、耗时  
- 报表：Excel/CSV/PDF  

### E. 系统公共

用户角色、组织人员、项目、数据集、文件存储、标签体系、任务、操作日志、导入导出、统计分析驾驶舱。

---

## 4. 非功能需求

| 项 | 要求 |
|----|------|
| 真实性 | 禁止纯静态页、固定模拟代替业务、空按钮、未接通算法标完成 |
| 持久化 | 业务数据落库；文件落对象存储或本地 storage |
| 可演示 | 单机 Docker Compose 或本地一键启动；15 分钟连续操作脚本 |
| 性能 | 标注保存 < 500ms；预标单张图 YOLO < 10s（CPU）；训练首 epoch 可见指标 |
| 安全 | JWT；密码哈希；操作审计；敏感样例脱敏 |
| 可追溯 | 样本↔标注↔审核↔模型版本↔训练任务关联 |

---

## 5. 验收原则（摘要）

- 每个评分项有明确菜单入口且可真实操作  
- 数据可保存查询；导出文件可打开核验字段  
- NLP/OCR/YOLO 执行真实推理（可 CPU）  
- VLA 五模态关联可在 JSON 中核验  
- 质量检测对上传样本产出可定位异常  
- 训练任务产生真实日志驱动的曲线，非 PRNG 假数
