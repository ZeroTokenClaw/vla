## 3. 关键页面交互规格

### 3.1 标注工作台 `/qc/annotate/:id`（1.5 分核心）

布局：左任务列表 | 中操作区 | 右标签属性。

| 模态 | 中区交互【升级】 | 右区 | 输出 |
|------|------------------|------|------|
| 文本 | 拖选建实体、高亮、关系连线 | 类型/属性/关系 | annotation_result JSON |
| 分割 | 缩放拖动、多边形、画笔橡皮、图层 | 类别/可见性 | mask PNG + 矢量 |
| 语音 | 波形、缩放、拖拽起止、播放 | 说话人/转写 | 切片 wav + meta |
| 视频 | 播放/逐帧/时间轴画框 | 类别/track_id | 逐帧 bbox JSON |
| 点云 | Three.js 旋转缩放、框选着色 | 类别 | 点索引/标签导出 |

公共：保存、提交审核、历史、快捷键。

### 3.2 VLA 多模态工作台 `/vla/timeline/:id`（3 分核心）

布局：左样本列表 | 中视频+时间轴+动作条 | 右指令/节点/属性。

必须可操作：打关键节点、起止帧、动作排序、文本指令编辑、三格式导出按钮各自独立下载。

### 3.3 预标视觉页 `/prelabel/vision`

上传/选图 → 选模型版本 → 运行 OCR/YOLO（显示进度）→ 结果叠框 → 人工改 → 保存 Diff。

### 3.4 训练运行 `/train/runner/:id`

启动后 WebSocket/轮询推送 epoch 指标；曲线来自 `training_metrics` 表；可暂停/恢复/终止。

### 3.5 运营驾驶舱 `/`

卡片：标注量、合格率、预标吞吐、VLA 任务、GPU 利用率、训练中实验；图表接真实聚合 API。
