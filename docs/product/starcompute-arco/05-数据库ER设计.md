# 《数据库 ER 设计》

> 引擎：PostgreSQL 15+（演示可用 SQLite）  
> ORM：SQLAlchemy 2.x  
> 约定：主键 `id` 字符串业务号或 UUID；时间 `created_at`/`updated_at`；软删 `deleted_at`。

---

## 1. 表清单（核心）

### 1.1 用户与权限

| 表 | 关键字段 | 索引 |
|----|----------|------|
| `user` | id, username, password_hash, name, org_id, status | uk(username) |
| `role` | id, code, name | uk(code) |
| `permission` | id, code, name | uk(code) |
| `user_role` | user_id, role_id | pk(user_id,role_id) |
| `role_permission` | role_id, permission_id | pk |
| `organization` | id, name, parent_id | |

### 1.2 项目与数据

| 表 | 关键字段 | 关联 |
|----|----------|------|
| `project` | id, name, code, owner_id, status | → user |
| `dataset` | id, project_id, name, modality, version | → project |
| `sample` | id, dataset_id, name, modality, status, meta_json | → dataset |
| `sample_file` | id, sample_id, file_type, path, checksum, duration_ms | → sample |
| `label_schema` | id, project_id, name, modality | |
| `label_item` | id, schema_id, code, name, color, parent_id | |
| `file_asset` | id, path, mime, size, uploader_id | |

### 1.3 标注协作与质控

| 表 | 关键字段 | 枚举 |
|----|----------|------|
| `annotation_task` | id, project_id, dataset_id, modality, status, priority, spec_id, start_at, due_at | status 见下 |
| `task_assignment` | id, task_id, user_id, role, sample_ids_json, claimed_at | |
| `annotation_result` | id, task_id, sample_id, version, payload_json, mask_path, actor_id | |
| `annotation_comment` | id, task_id, sample_id, author_id, body | |
| `review_record` | id, task_id, level(1-3), reviewer_id, decision, comment | |
| `review_history` | id, task_id, from_status, to_status, actor_id, reason | |
| `quality_rule` | id, name, ratio, modalities_json, threshold, enabled | |
| `quality_inspection` | id, rule_id, task_id, mode(random/指定), status | |
| `quality_record` | id, inspection_id, sample_id, result(pass/fail), reason | |

**annotation_task.status**：  
`pending_assign` → `pending_annotate` → `annotating` → `pending_review` → `reviewing` → `passed`  
驳回：`reviewing` → `rejected` → `pending_rework` → `resubmitted` → `reviewing` → `passed`

（前端可与现有 `created/assigned/...` 做映射表兼容。）

---

## 2. 关键外键关系（摘要）

- `sample.dataset_id` → `dataset.id`  
- `annotation_result(task_id, sample_id)` → task/sample  
- `preannotation_result` 同时存 `model_payload` 与 `human_payload`  
- `modality_relation.sample_id` 统一挂接 VLA 多模态  
- `training_metrics.task_id` → `training_task`；`map_metric` 明确口径如 `mAP@0.5`
