# 《算法服务接入文档》

> 目标：所有预标注、质检、训练、评测均通过可替换的算法服务接口执行。  
> Worker：Celery 任务；同步调试可用 FastAPI 内嵌调用。

---

## 1. 服务清单

| 服务 ID | 能力 | 推荐实现 | 输入 | 输出 |
|---------|------|----------|------|------|
| `nlp.classify` | 文本分类 | transformers / 规则降级 | text, labels[] | [{label, conf}] |
| `nlp.ner` | 实体识别 | spaCy / transformers | text | [{start,end,type,text,conf}] |
| `nlp.relation` | 关系抽取 | 规则+实体对 / 模型 | text, entities | [{head,tail,type,conf}] |
| `vision.ocr` | OCR | PaddleOCR | image_path | [{box,text,conf}] |
| `vision.yolo` | 目标检测 | YOLOv8n | image_path, conf_thres | [{box,cls,conf}] |
| `vision.seg` | 分割辅助 | SAM 可选 | image, prompt | mask |
| `audio.vad_slice` | 语音切片 | FFmpeg+webrtcvad | wav_path | [{start_ms,end_ms,path}] |
| `vla.quality` | 五类质检 | OpenCV 启发式 | video/image meta | issues[] |
| `vla.consistency` | 指令一致性 | 规则对齐 + 可选 LLM | instruction, actions | score, mismatches |
| `train.torch_mini` | 迷你训练 | PyTorch | config, dataset | metrics/epoch + ckpt |
| `eval.run` | 模型评测 | 任务相关指标脚本 | model_version, dataset | metrics map |

---

## 2. 统一调用契约

```json
{
  "request_id": "EIDE-REQ-...",
  "service_id": "vision.yolo",
  "source_mode": "real",
  "model_version": "yolov8n-2026.11",
  "inputs": { "image_path": "storage/..." },
  "params": { "conf_thres": 0.25 }
}
```

```json
{
  "request_id": "EIDE-REQ-...",
  "status": "succeeded",
  "source_mode": "real",
  "model_version": "yolov8n-2026.11",
  "latency_ms": 812,
  "result": {},
  "error": null
}
```

`source_mode`：
- `real`：真实模型/训练进程  
- `test`：算法未部署时的测试桩；**UI 必须黄标「测试模式」**，禁止与 real 混排为同一「真实结果」列表而不加标识  

---

## 3. 接入步骤

1. 在 `eide-platform/algo/` 实现各 `service_id` Runner。  
2. 注册到 `algo_registry`（代码字典或 DB）。  
3. Celery task：`run_algo(service_id, payload)` → 写结果表。  
4. 健康检查：`GET /api/v1/algo/health` 返回各服务 `up/down/test_only`。  
5. 前端根据 health 展示模式徽章。

---

## 4. 资源与性能基线（演示机）

| 服务 | 硬件 | 目标时延 |
|------|------|----------|
| OCR 单图 | CPU | < 5s |
| YOLO 单图 | CPU | < 10s |
| NER 短文本 | CPU | < 2s |
| 质检 10s 视频 | CPU | < 30s |
| 迷你训练 1 epoch | CPU/GPU | 可见 metrics 写入 |

权重默认放 `eide-platform/models/`；首次启动可自动下载轻量权重（需网络）或使用随包 stub。

---

## 5. 失败与降级

| 情况 | 行为 |
|------|------|
| 权重缺失 | 返回 503 + `test_only` 建议 |
| 推理异常 | job=failed，可 retry |
| 超时 | 可配置；默认 120s |
| 用户强制测试模式 | 仅 admin；结果强制 `source_mode=test` |

---

## 6. 安全

- 仅处理本机 `storage/` 内路径；禁止任意路径读。  
- 上传文件类型白名单与大小限制。  
- 不在日志打印完整样本原文（可截断）。
