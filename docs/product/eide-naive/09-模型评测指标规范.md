# 《模型评测指标规范》

> 规范版本：`EIDE-ME-1.0`  
> 原则：指标必须来自真实训练日志或评测脚本输出；禁止 PRNG/手写常数冒充。

---

## 1. 训练过程指标

| 指标 | 字段 | 定义 | 记录频率 |
|------|------|------|----------|
| Train Loss | `train_loss` | 训练集损失 | 每 epoch |
| Val Loss | `val_loss` | 验证集损失 | 每 epoch |
| Accuracy | `accuracy` | 分类正确率 | 每 epoch |
| Precision | `precision` | TP/(TP+FP) | 每 epoch 或评测 |
| Recall | `recall` | TP/(TP+FN) | 每 epoch 或评测 |
| mAP | `map_value` + `map_metric` | 如 mAP@0.5 | 检测任务 |
| LR | `lr` | 当前学习率 | 每 epoch |
| Elapsed | `elapsed_sec` | 耗时 | 每 epoch |

写入表 `training_metrics`；曲线仅读取该表。

---

## 2. 任务类型与主指标

| 任务 | 主指标 | 辅指标 |
|------|--------|--------|
| 图像分类 | Accuracy | P/R/F1 |
| 目标检测 | mAP@0.5 | mAP@0.5:0.95, FPS |
| OCR | 字符准确率 / 行准确率 | 置信度分布 |
| NER | Entity F1 | Precision/Recall |
| VLA 策略（迷你） | 动作类型 Acc / 成功率 | 轨迹误差（可选） |

---

## 3. 多模型对比评测

`eval_task` 约束：
1. 同一 `dataset_id`（含固定 split）  
2. ≥2 个 `model_version_id`  
3. 统一 `metric_set`  
4. 跑完后写 `eval_result`；报告含表 + 雷达图数据  

对比表字段：`model_version, metric_name, metric_value, latency_ms, params_count?, trained_on_dataset`。

---

## 4. 指令-动作一致性（行为评测）

| 分项 | 计算 |
|------|------|
| 词汇对齐 | 指令关键词命中动作 attrs/类型 |
| 时序覆盖 | 指令步骤数 vs 动作段数 |
| 关键节点覆盖 | 必选节点是否存在 |
| 综合分 | 加权平均 0–1 |

结果进 `instruction_action_score`，可纳入评测报告扩展页。

---

## 5. 报表导出

- CSV/Excel：epoch 明细或对比宽表  
- 元数据头：`task_id, model_version, dataset_version, generated_at, source_mode`  
- `source_mode=test` 的报表文件名加 `_TESTMODE`

---

## 6. 验收红线

1. 不得使用 `mockMetricPoint` 作为 REAL 模式数据源。  
2. 评测未完成不得显示最终分数。  
3. 血缘缺失（无 dataset/model 边）时对比报告显示警告。
