# 《数据质量检测规则》

> 规则版本：`EIDE-QR-1.0`  
> 适用范围：样本级 / 数据集级 / 任务级评分与 VLA 五类异常

---

## 1. 质量评分卡维度

| 维度 | 权重（默认） | 说明 |
|------|-------------|------|
| 完整性 Completeness | 0.25 | 必需模态/字段缺失率 |
| 清晰度 Clarity | 0.20 | 模糊、曝光、噪声 |
| 稳定性 Stability | 0.15 | 抖动、丢帧 |
| 标注一致性 LabelConsistency | 0.20 | 标签规范符合度、审核驳回率 |
| 任务匹配 TaskMatch | 0.20 | 指令与场景/动作匹配 |

**总分** = Σ(维度分 × 权重)，维度分 0–100。  
等级：`A≥90` / `B≥80` / `C≥70` / `D≥60` / `E<60`。

---

## 2. VLA 五类异常检测

| 类型 | code | 检测方法（演示可落地） | 定位 | 默认阈值 |
|------|------|------------------------|------|----------|
| 抖动 | `shake` | 帧差光流幅值均值过高 | 帧区间 | mean_flow > T_shake |
| 遮挡 | `occlusion` | 前景面积突降 / 检测框消失 | 帧 | drop_ratio > 0.5 |
| 模糊 | `blur` | Laplacian 方差过低 | 帧 | var < T_blur |
| 数据缺失 | `missing` | 必需文件/字段/时间戳空洞 | 样本 | 任一必需缺失 |
| 任务不匹配 | `mismatch` | 指令关键词与动作类型/场景标签不对齐 | 样本/动作 | consistency < 0.6 |

检测结果写入 `vla_quality_result` / `anomaly_ticket`，支持人工复核后 `confirm` / `dismiss`。

---

## 3. 多模态标注质检规则

| 规则 ID | 条件 | 动作 |
|---------|------|------|
| QC-R01 | 实体重叠率 > 0.9 且类型相同 | 警告重复 |
| QC-R02 | 分割多边形点数 < 3 | 拒绝保存 |
| QC-R03 | 语音切片 end ≤ start | 拒绝保存 |
| QC-R04 | 视频框越界图像 | 自动裁剪或拒绝 |
| QC-R05 | 必填属性空 | 不可提交审核 |
| QC-R06 | 抽检不合格率 ≥ 阈值 | 任务打回 |

---

## 4. 数据集级聚合

- 缺失率 = 缺模态样本 / 总样本  
- 异常率 = 未关闭 anomaly / 总样本  
- 合格率 = quality_pass 样本 / 已质检样本  
- 画像快照每日或手动 refresh 写入 `data_profile_snapshot`

---

## 5. 不合格处理闭环

```
检测 → 生成 anomaly_ticket → 人工确认
  ├─ 可修复：返修标注 / 重采集
  ├─ 过滤：标记 filtered，导出默认排除
  └─ 误报：dismiss + 原因
```

过滤后的样本不得进入训练数据集默认视图，除非管理员强制包含。

---

## 6. 配置项

所有阈值存 `quality_rule.params_json`，支持按项目覆盖；变更写操作日志。
