# 《现有系统功能盘点与差距分析》

> 产品基线：灵眸 VLA Studio（`vla-demo-naive`）  
> 目标产品：EIDE — 具身智能数据智能分析与模型评测平台  
> 分析日期：2026-11-09  
> 结论先行：**四大招标模块在前端演示闭环已齐备；按「真实后端 / 真实算法 / 持久化 / 可验证评测」标准仍属 mock；EIDE 差异化能力（数据画像、质量评分、动作语义、多模型评测、数据-模型追溯）几乎全部缺失。**

---

## 1. 技术栈与工程现状

| 项 | 现状 | EIDE 目标 |
|----|------|-----------|
| 定位 | 深色创作台演示前端 | 数据分析 + 行为理解 + 模型评测平台 |
| 技术栈 | Vue3.5 + Vite8 + Naive UI + Pinia + ECharts + xlsx + Vitest | 复用前端壳；新增 FastAPI + SQLAlchemy + Redis + Celery + 算法 Worker |
| 端口 | `5103` | 前端 `5103`；后端 `8103` |
| 数据层 | `src/mock/*` 内存种子 + `businessDelay` | PostgreSQL/SQLite + 对象存储 + 任务队列 |
| 权限 | 顶栏三角色切换 | JWT + RBAC；保留演示三角色 |
| 品牌 | 灵眸 VLA Studio / LM | EIDE / 数据智能分析台 |
| 任务前缀 | `LM-` | `EIDE-` / `EA-` / `EP-` / `EV-` / `ET-` |
| 后端/算法 | **不存在** | `eide-platform/` |

```
vla-demo-naive/
├── src/views/{qc,prelabel,vla,train}/   # 四大演示模块
├── src/services/{qc,prelabel,vla,train}.js

```

## 2. 模块能力判定

| 业务模块 | 路由 | 演示覆盖 | 工程真实度 | EIDE 缺口 |
|----------|------|----------|------------|-----------|
| QC 质控 | `/qc/*` | 齐 | 内存状态机 | 缺深度画布 + 持久化；缺「质量画像」入口 |
| Prelabel | `/prelabel/*` | 齐 | 预置结果 | **无真实 NLP/OCR/YOLO** |
| VLA | `/vla/*` | 齐 | 导出真实、质检种子 | 缺动作语义分析、指令一致性 |
| Train | `/train/*` | 齐 | **`mockMetricPoint`** | **严重不达标**；缺多模型对比与追溯 |
| 数据画像/异常 | — | 无 | — | **P0 缺失** |
| 质量评分中心 | 分散在抽检/质检 | 弱 | — | **P0 需中心化** |
| 评测对比/血缘 | — | 无 | — | **P0 缺失** |

## 3. 招标 20 分差距摘要

| 分项 | 分值 | 演示 | 真实工程 |
|------|------|------|----------|
| 多模态标注 | 1.5 | 部分（列表式标签） | 缺多边形/波形裁剪/逐帧框/真三维 |
| 协作审核 | 1.5 | 已实现 | 缺持久化与并发 |
| 抽检回流 | 1.0 | 已实现 | 缺回流真实数据集 |
| NLP 预标 | 1.5 | 已实现 | 无真实推理 |
| OCR/YOLO | 1.0 | 已实现 | 无真实模型 |
| 预标验收 | 1.5 | 已实现 | Diff 未量化入库 |
| VLA 采集配置 | 2.5 | 部分 | 缺设备/频率完整模型 |
| VLA 联动标注导出 | 3.0 | 已实现（三格式真实下载） | 需服务端归档 |
| VLA 样本质检 | 2.5 | 种子 issues | 非视觉算法 |
| 训练配置 | 2.0 | 已实现 | 缺真实 GPU/进程 |
| 训练指标 | 2.0 | **模拟曲线** | **必须改为真实日志** |

## 5. 风险与约束

1. **表述风险**：对外不得宣称已具备真实推理/训练。  
2. **同源四套**：与 element/antd/arco 共享演示骨架，EIDE 必须重构 IA 与分析主路径，避免「换皮」。  
3. **点云**：现状为 2D 预览图，真三维为 P1 可演示增强。  
4. **算法未部署**：允许明确标识的测试模式，但 UI 必须与真实模式严格区分。  

下一步：按 `01`–`13` 文档实施；研发分期见 `10-功能研发任务清单.md`。
