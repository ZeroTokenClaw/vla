# 《产品需求规格说明书》（PRD）

> 产品名称：EIDE — 具身智能数据智能分析与模型评测平台  
> 版本：V1.0  
> 基线前端：`vla-demo-naive`  
> 工程目录：`eide-platform/`（后端 + 算法服务）

---

## 1. 产品目标

建设可独立运行的专业级平台，完整覆盖招标 **20 分** 四大模块，并突出 EIDE 差异化：

1. 多模态数据分析与真实标注质控  
2. AI 智能预标注（真实推理 + 人工修正 + 验收）  
3. VLA 行为理解（采集、联动标注、动作语义、一致性、质量门禁）  
4. 算法训练监控与多模型性能评测、数据-模型追溯  

**非目标（V1）**：公有云多租户计费、完整 MLOps 平台、机器人实机遥操作、大规模分布式训练调度。

---

## 2. 用户与角色

| 角色 | 职责 |
|------|------|
| 分析员 analyst | 数据画像、质量评分、异常定位（可映射 reviewer 扩展） |
| 标注员 annotator | 多模态标注、预标修正、VLA 时间轴/动作标注 |
| 审核员 reviewer | 多级审核、抽检、预标验收、VLA 质量复核 |
| 评测员 evaluator | 模型评测对比、指标分析（可映射 admin 子角色） |
| 管理员 admin | 项目/数据集/用户、训练启停、GPU、系统配置 |

所有状态变更必须记录：操作人、时间、前后状态、原因。

---

## 3. 功能需求

### A. 多模态数据分析与标注中心（对应招标 4 分 + 画像能力）

- 数据画像：按模态/场景/任务统计分布、缺失率、标签覆盖、时长直方图  
- 质量评分：样本/数据集/任务三级评分卡（规则见文档 08）  
- 异常分析：抖动、遮挡、模糊、缺失、任务不匹配统一入口与定位  
- 标注工作台：文本实体/关系、图像分割、语音切片、视频检测、点云分割  
- 协作：任务创建、分配、认领、批注、驳回返修、多级审核、抽检回流  

### B. AI 智能预标注中心（对应招标 4 分）

- 文本：分类、实体识别、关系抽取 → 结构化 JSON  
- 视觉：OCR、YOLO 检测；展示置信度；人工修正；Diff 保存  
- 验收：确认 → 标注复核 → 质检 → 入库  
- 必须对接真实算法服务；未部署时仅允许「测试模式」标识  

### C. VLA 智能行为理解中心（对应招标 8 分 + 语义能力）

- 采集：任务、场景、方案、模式、动作模板、人员  
- 联动浏览：视频 / 图像 / 文本说明 / 任务指令  
- 标注：动作序列、关键动作节点、起止帧  
- 分析：动作序列统计、关键节点密度、指令-动作一致性评分  
- 导出：JSON / Excel / CSV 真实文件 + export_task  
- 质检：五类异常检测、不合格标记与过滤  

### D. 算法训练与模型评测中心（对应招标 4 分 + 评测能力）

- 配置：算法、版本、模型、超参、GPU 分配、数据增强  
- 运行：启动/暂停/恢复/终止；真实 metrics 落库  
- 展示：Loss、Accuracy、mAP 趋势；多实验对比  
- 评测：多模型同数据集对比表；报表导出  
- 追溯：数据集版本 ↔ 标注版本 ↔ 模型版本 ↔ 评测报告  

### E. 系统公共

项目、数据集、样本文件、标签体系、用户角色、操作日志、导入导出中心。

---

## 4. 非功能需求

| 项 | 要求 |
|----|------|
| 真实性 | 禁止静态假页、空按钮、伪造训练指标冒充真实结果 |
| 持久化 | 业务落库；文件落 storage；审计可查询 |
| 可演示 | 单机 Compose 或本地一键；15 分钟连续脚本 |
| 性能 | 标注保存 < 500ms；YOLO 单图 CPU < 10s；训练首 epoch 可见指标 |
| 安全 | JWT；密码哈希；操作审计；样例脱敏 |
| 模式隔离 | `REAL` / `TEST_MODE` 必须在 UI 与结果元数据中显式标识 |

---

## 5. 验收原则

- 每个评分项有独立可操作入口  
- 导出文件可打开核验字段  
- NLP/OCR/YOLO 执行真实推理（可 CPU）或明确测试模式  
- VLA 五模态关联可在 JSON 核验  
- 质量检测可定位异常样本  
- 训练曲线来自真实训练日志  
- 评测对比与血缘图可追溯  

详见 `11`、`12`、`13` 文档。
