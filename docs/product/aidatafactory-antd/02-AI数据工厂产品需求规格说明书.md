# 《AI 数据工厂产品需求规格说明书》

> 产品中文名：AI 多模态数据生产自动化工厂  
> 产品英文名：AI Data Factory（ADF）  
> 基线工程：`vla-demo-antd`（Ant Design Vue，端口 5102）  
> 版本：v1.0 / 2026-11-09

---

## 1. 产品目标

面向人工智能与具身智能模型训练，建设集多模态数据接入、自动化处理、AI 预标注、人工协作标注、VLA 数据生产、质量检测、算法训练与模型验证于一体的自动化数据生产平台。

与传统标注平台的本质差异：

1. 以**数据生产流水线**为核心，而非以单条标注工单为核心。  
2. 以**自动化任务编排**为主要能力。  
3. 以**多模态 AI 算法服务**为执行引擎。  
4. 以**人工审核**作为质量控制节点。  
5. 以**VLA 结构化数据**作为核心生产对象。  
6. 以**模型训练与验证**作为最终业务闭环。

**验收总则**：招标 20 分全部功能点必须可通过真实系统操作验证；不得删除、弱化或用静态流程图替代可执行逻辑。

## 2. 用户角色

| 角色 | 职责 | 核心权限 |
|------|------|----------|
| 生产管理员 | 创建生产任务、编排流程、监控工厂运行 | 全模块配置与调度 |
| 标注员 Annotator | 多模态标注、预标修正、VLA 动作标注 | 认领/标注/提交 |
| 审核员 Reviewer | 一级/二级审核、抽检、预标验收 | 通过/驳回/返修 |
| 算法工程师 | 算法配置、训练、评测、模型版本 | 训练与 GPU |
| 采集负责人 | VLA 采集任务、场景方案、人员设备 | 采集配置与导出 |
| 系统管理员 | 用户权限、日志、基础数据 | RBAC / 审计 |

演示期保留三角色切换；工程期映射为上述 RBAC。

## 3. 功能需求（按七大中心）

### 3.1 AI 数据生产任务中心（差异化核心）

**FR-PROD-01 生产任务创建**  
支持配置：任务名称、类型、描述、数据来源、数据类型、目标数据集、生产流程模板、执行人员、审核人员、优先级、执行时间、完成条件。

**FR-PROD-02 自动化流程编排**  
可视化工作流编辑器，支持 16 类节点（导入、解析、抽帧、OCR、YOLO、NLP、关系抽取、语义分割、语音切片、点云分割、人工标注、质量检测、人工审核、VLA 结构化、导出、算法训练）。  
必须支持：拖拽、连线、参数配置、执行顺序、条件分支、失败重试、保存、版本管理、运行、日志、结果查看。  
**每个节点必须有实际执行逻辑**，禁止仅展示流程图。

**FR-PROD-03 任务执行监控**  
展示任务总量、执行中、等待、已完成、失败、耗时、节点状态、进度、异常、重试、执行日志。  
大文件解析与模型推理必须异步，不得阻塞 Web 请求。

### 3.2 多模态智能标注中心（4 分）

| ID | 需求 | 分值 |
|----|------|------|
| FR-QC-01 | 文本实体抽取（导入/浏览/边界/类别/关系/导出） | 计入 1.5 |
| FR-QC-02 | 图像语义分割（缩放/多边形/像素级/Mask） | 计入 1.5 |
| FR-QC-03 | 语音切片（波形/起止/说话人/文本关联） | 计入 1.5 |
| FR-QC-04 | 视频目标检测（逐帧/画框/ID/跟踪） | 计入 1.5 |
| FR-QC-05 | 点云分割（PCD/PLY/BIN、三维交互） | 计入 1.5 |
| FR-QC-06 | 任务协作与多级审核状态机 | 1.5 |
| FR-QC-07 | 质量抽检、规范、回流与质量报表 | 1.0 |

状态机（必须完整）：

```
待分配 → 待标注 → 标注中 → 待审核 → 审核中 → 已通过
审核中 → 已驳回 → 待返修 → 重新提交 → 复审 → 已通过
```

### 3.3 AI 自动预标注中心（4 分）

| ID | 需求 | 分值 |
|----|------|------|
| FR-PL-01 | NLP：分类/NER/关系/边界/置信度/JSON/人工修改 | 1.5 |
| FR-PL-02 | OCR + YOLO 真实推理服务调用与人工改框 | 1.0 |
| FR-PL-03 | 验收全流程：创建→选择→配置→推理→确认修正→质检→验收→回流 | 1.5 |

必须支持模型服务注册、版本管理、推理参数、批量任务、失败重试；保存模型预测、人工修正、最终验收三套结果。

### 3.4 VLA 智能采集与数据生产中心（8 分）

| ID | 需求 | 分值 |
|----|------|------|
| FR-VLA-01 | 采集任务/场景/方案/模式/动作模板/人员配置 | 2.5 |
| FR-VLA-02 | VLA 工作台多模态联动 + JSON/Excel/CSV 真实导出 | 3.0 |
| FR-VLA-03 | 抖动/遮挡/模糊/缺失/不匹配检测与不合格处理 | 2.5 |

多模态关联强制实现：

`任务指令 ↔ 视频 ↔ 图像 ↔ 文本说明 ↔ 动作序列 ↔ 关键动作节点`

关联键：`sampleId` + `taskId` + `timestamp` / `frameIndex`。

### 3.5 数据质量检测中心

统一承载：标注抽检、预标验收质检、VLA 自动化质检、异常样本处理与回流统计。可作为独立导航入口聚合既有能力。

### 3.6 AI 算法训练与验证中心（4 分）

| ID | 需求 | 分值 |
|----|------|------|
| FR-TR-01 | 算法/版本/模型/超参/GPU 分配与训练任务生命周期 | 2.0 |
| FR-TR-02 | 增强、真实指标曲线、评测、报表（Excel/PDF/CSV） | 2.0 |

**禁止**使用固定或公式伪造的 loss/acc/mAP；指标必须来自实际训练运行或可核验的评估日志。

### 3.7 生产运营及任务监控中心

数据生产驾驶舱：产能、任务漏斗、节点失败率、模态产量、人员质量、GPU 利用率、导出与回流概况。

### 3.8 公共基础能力

用户权限、项目管理、数据集管理、模型服务管理、文件管理、标签规范、任务调度、消息通知、操作日志、导入导出、统计分析——均需有页面或明确模块入口，数据可持久化。

## 6. 数据与集成需求

- 至少实现需求文档第八章列出的 28 个核心实体及关联。  
- 算法服务独立进程，支持状态回传、失败重试、运行日志。  
- 导出 JSON / Excel / CSV 必须真实生成可下载文件。  
- 训练与预标结果可回流 Dataset，供后续生产任务引用。

---

## 7. 验收标准（摘要）

1. 20 分评分矩阵每一子项均有可点击入口与可核验结果。  
2. 工作流至少一条端到端流水线可跑通：导入 → 预标 → 人工审核 → VLA 结构化 → 导出 → 训练。  
3. OCR、YOLO、训练指标、VLA 质检至少一路可展示真实算法输出（或半真实 Worker 日志）。  
4. 刷新页面后关键业务数据不丢失（工程模式）。  
5. 15 分钟演示脚本可完整覆盖评分点。

详细用例见《14-功能测试验收报告》与《15-15分钟视频演示脚本》。
