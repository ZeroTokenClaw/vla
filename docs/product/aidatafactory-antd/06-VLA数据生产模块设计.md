# 《VLA 数据生产模块设计》

> 对应评分：6.1（2.5）+ 6.2（3.0）+ 6.3（2.5）= 8 分  
> 优先级：系统最高  
> 基线：`/vla/collect` `/vla/timeline` `/vla/quality`

---

## 1. 模块拆分（对齐 28 页面）

| 页面 | 路由 | 说明 |
|------|------|------|
| VLA 采集任务中心 | `/vla/collect` | 任务 CRUD、人员、状态 |
| 场景及采集方案中心 | `/vla/scenes` | 场景/方案独立管理【升级拆分】 |
| 动作模板管理 | `/vla/templates` | 模板库【升级拆分】 |
| VLA 多模态标注工作台 | `/vla/timeline/:id?` | 核心联动标注 |
| VLA 数据质量检测 | `/vla/quality/:id?` | 五类检测 |
| 数据异常处理中心 | `/vla/exceptions` | 不合格批处理【升级】 |
| 数据导出中心 | `/export` | 跨模块导出归档【升级】 |

## 2. 采集任务管理（2.5）

### 2.1 任务字段

任务名称、编号、描述、采集目标、任务类型、采集设备、机器人型号、负责人、采集人员、审核人员、任务时间、状态。

### 2.2 场景信息

场景名称、分类、描述、图片、环境信息、空间信息、标签。

### 2.3 采集方案

目标、步骤、频率、时长、设备、数据类型、质量要求。

### 2.4 采集模式

视频 / 图像 / 连续动作 / 单次动作 / 多模态同步 / 机器人执行 / 人工示范。

### 2.5 动作模板

名称、类别、描述、执行步骤、开始/结束条件、关键节点、可复用。

### 2.6 人员与工作量

负责人、执行、审核、分配、权限；统计已完成 episode 数与标注节点数。

## 3. VLA 多模态联动标注工作台（3）

### 3.1 布局

```
┌────────────┬──────────────────────────────┬─────────────────┐
│ 左：任务列表 │ 中：视频/图像/双时间轴         │ 右：指令与属性   │
│ 样本列表    │ 视频播放 · 关键帧 · 动作轴      │ 场景说明         │
│ 场景/模板   │                              │ 动作描述/标签    │
│            │                              │ 起止帧配置       │
└────────────┴──────────────────────────────┴─────────────────┘
```

### 3.2 能力清单

| 能力 | 实现要点 |
|------|----------|
| 视频控制 | 播/停/逐帧/时间轴定位/关键帧提取 |
| 图文关联 | 帧 ↔ 图像预览 ↔ timestamp |
| 任务指令 | 自然语言指令、执行目标、步骤、语义编辑 |
| 动作序列 | 片段创建、分类、排序、起止时间、语义 |
| 关键节点 | 名称、类型、时间戳、对应帧/图、语义、标签 |
| 起止帧 | 选择、调整、片段预览、保存 |

### 3.3 多模态关联模型

```
VLATask
  └── Sample (episode)
        ├── instruction (text)
        ├── video (uri, fps)
        ├── images[] (frameIndex, uri, ts)
        ├── ActionSequence[]
        │     └── ActionNode[] (ts, frame, imageId, label)
        └── ModalityRelation (edges)
```

关联查询键：`taskId + sampleId + timestamp|frameIndex`。

### 3.4 导出（必须真实生成文件）

| 格式 | 内容 |
|------|------|
| JSON | 完整 VLA 结构（任务/样本/指令/动作/节点/关系） |
| Excel | 任务、样本、动作节点、标注结果多 Sheet |
| CSV | 样本、动作标签、时间序列扁平行 |

实现：复用并扩展 `exportFiles.js`；工程模式同时写 `ExportTask` 与对象存储。

## 4. 与生产流水线集成

工作流节点 `vla_struct`：读取采集任务 → 校验关联完整性 → 写出结构化包。  
工作流节点 `quality_check`（VLA 规则集）：调用质检算法（见《07》）。  
工作流节点 `export`：触发三格式导出。

---

## 5. 验收要点

1. 创建含场景/方案/模式/模板/人员的采集任务。  
2. 工作台完成动作片段 + 关键节点 + 起止帧保存。  
3. 证明 instruction/video/image/action/node 互相关联。  
4. 三种格式均可下载且内容字段齐全。  
5. 质检与异常处理可改变合格集（见《07》）。
