# 《多模态标注工作台设计》

> 对应评分：4.1（1.5）+ 4.2（1.5）+ 4.3（1.0）  
> 基线页面：`/qc/annotate`、`/qc`、`/qc/workflow`、`/qc/audit`、`/qc/sample-check`、`/qc/spec`

---

## 1. 信息架构

```
多模态智能标注中心
├─ 标注任务管理        /qc
├─ 多模态标注工作台    /qc/annotate/:id?
├─ 多人协作中心        /qc/workflow
├─ 标注审核中心        /qc/audit/:id?
├─ 质量抽检中心        /qc/sample-check
└─ 标注规范            /qc/spec
```

升级：状态文案映射为招标用语；保留内部 enum 兼容现有 `TRANSITIONS`。

| 招标文案 | 内部 status |
|----------|-------------|
| 待分配 | `created` |
| 待标注 | `assigned` |
| 标注中 | `annotating` |
| 待审核 | `pending_review`（新增，或由 reviewing 队列表达） |
| 审核中 | `reviewing` / `final_review` |
| 已通过 | `done` |
| 已驳回 | `rejected` |
| 待返修 | `to_fix`（可由 rejected+标志表达） |

## 2. 五类模态工作台

公共布局：

```
┌──────────────┬────────────────────────────┬─────────────────┐
│ 任务头信息    │ 画布 / 播放器 / 三维视图     │ 标签与属性面板   │
│ 模态切换      │ 工具条（缩放/撤销/类别）     │ 结果列表         │
│ 历史批注入口  │                            │ 保存 / 提交审核  │
└──────────────┴────────────────────────────┴─────────────────┘
```

### 2.1 文本实体抽取

| 能力 | 交互 | 数据 |
|------|------|------|
| 导入/浏览 | 任务绑定文本 Sample | `content` |
| 片段选择 | 鼠标拖选 | `start,end` |
| 实体标记 | 选类别落实体 | `entities[]` |
| 关系建立 | 选头尾实体+关系类型 | `relations[]` |
| 导出 | 结构化 JSON | AnnotationResult |

### 2.2 图像语义分割

| 能力 | 交互 | 升级点 |
|------|------|--------|
| 预览缩放 | 滚轮/按钮 | 已有预览 |
| 多边形绘制 | 点击加点、闭合 | **P1 必须补** |
| 像素级/画笔 | 可选 brush | P1 |
| Mask 生成 | RLE / PNG | 保存到对象存储 |
| 区域编辑 | 选中改点/删 | 右侧列表联动 |

### 2.3 语音切片

| 能力 | 交互 |
|------|------|
| 播放/波形 | wavesurfer 或 canvas 波形 |
| 时间轴选起止 | 拖拽区域 |
| 说话人 | 下拉 speakerId |
| 文本关联 | transcript 字段 |

### 2.4 视频目标检测

| 能力 | 交互 |
|------|------|
| 播放/逐帧 | video + frame slider |
| 画框 | 当前帧拖拽 bbox |
| 类别 / trackId | 右侧表单 |
| 跟踪 | 简单 IoU 提示下一帧（可半自动） |
| 导出 | 帧级 boxes JSON |

### 2.5 点云分割

| 能力 | 交互 |
|------|------|
| 导入 PCD/PLY/BIN | 解析为 Three.js BufferGeometry |
| 旋转缩放平移 | OrbitControls |
| 框选/套索 | 屏幕空间选择 → 点索引 |
| 分类保存 | segment label + indices |

演示降级策略：若 GPU/大文件受限，提供「标准样例点云」保证可操作；工程模式接 Open3D 预处理。

## 3. 协作与审核

### 3.1 任务管理

- 创建、分配、认领、多人协作（collaborators）。  
- 批注线程、问题反馈、操作日志（复用 audit）。  

### 3.2 审核

- 一级审核（Reviewer）、二级/终审（Admin）。  
- 驳回必须填写原因码；进入返修后重新提交复审。  
- `ReviewRecord` 全量保留。

### 3.3 质量抽检（1 分）

| 功能 | 说明 |
|------|------|
| 规则配置 | 比例、数量、模态范围、质量阈值 |
| 随机抽检 | 按比例从 done 池抽样 |
| 指定范围 | 按任务 ID / 时间窗 / 人员 |
| 规范管理 | Spec 文档 + 可配置标签体系（升级） |
| 合格/驳回/返修/回流 | 回流写入 Dataset |
| 报表 | 合格率、人员质量（P2） |

## 4. 数据契约（AnnotationResult）

```json
{
  "id": "AR-...",
  "sampleId": "S-...",
  "taskId": "ORN-...",
  "modality": "text_ner",
  "labels": {},
  "version": 3,
  "createdBy": "u1",
  "createdAt": "..."
}
```

工作台保存写 `labels`；提交审核不改内容只改任务状态。

---

## 5. 验收要点

1. 五模态均可完成「打开样例 → 编辑 → 保存 → 审计可见」。  
2. 协作链路可演示分配→标注→驳回→返修→终审通过。  
3. 抽检可演示随机抽检与回流 Dataset。  
4. 多边形分割、逐帧画框、点云三维为深度加分项，列入 P1，不得从评分矩阵删除。
