# 《15 分钟视频演示脚本》

> 产品：AI Data Factory（基于 `vla-demo-antd`）  
> 目标：覆盖招标 20 分 + 工厂流水线故事  
> 前置：`pnpm dev` → http://127.0.0.1:5102  
> 角色：开始用 Admin，标注段切 Annotator，审核段切 Reviewer

---

## 时间分配

| 段 | 时长 | 内容 | 分值 |
|----|------|------|------|
| A | 0:00–2:00 | 工厂驾驶舱 + 生产任务 + 跑流水线 | 差异化 |
| B | 2:00–5:00 | 多模态标注 + 协作审核 + 抽检 | 4 |
| C | 5:00–7:30 | NLP / OCR·YOLO / 验收 | 4 |
| D | 7:30–12:00 | VLA 采集 / 联动标注 / 导出 / 质检 | 8 |
| E | 12:00–15:00 | 训练配置 / 监控 / 报表 | 4 |

> 前端工厂模块已落地（`/factory/*`），使用逼真伪造数据；口播需声明 Demo Fake Data。

---

## A. 工厂流水线（2 min）

1. 打开 **Factory → 驾驶舱**（`/factory/dashboard`），指总量/执行中/失败率与图表。  
2. **生产任务** → Create：名称、类型、数据来源、目标 Dataset、流程模板、执行/审核人、优先级。  
3. 进入 **流程编排**（`/factory/workflows`）：展示 16 类节点库，打开预置「VLA 具身数据线」，可试运行看日志。  
4. 切到 **执行监控**：对 `ADF-PROD-2026-001` 点「推进一步 / 自动推进」，展示节点状态与日志；人工门禁可放行。  
口播要点：「节点可配置、可运行、有日志与产出摘要；本环境为伪造执行，不接真实模型。」

---

## B. 多模态标注与质控（3 min）

1. **QC → Annotate**：切换文本/分割/语音/视频/点云，各做一次保存。  
2. **Jobs**：创建或分配任务；切 Annotator 提交审核。  
3. **Workflow / Review**：Reviewer 驳回 → 返修 → Admin 终审通过。  
4. **Sampling**：设比例 → 随机抽检 → 合格回流；扫一眼 Spec。  

---

## C. 预标注（2.5 min）

1. **Text**：跑分类/NER/关系 → Diff 修正 → 保存。  
2. **Vision**：跑 OCR → 改字；跑 YOLO → 改框 → 保存（工程模式强调真实服务版本号）。  
3. **Accept**：Steps 走完确认→标注→质检→验收。  

---

## D. VLA（4.5 min）

1. **Collect**：创建任务，填场景/方案/模式/模板/人员（及设备若已上线）。  
2. **Timeline**：播放视频，加动作片段与关键节点，改起止帧，保存。  
3. 导出 **JSON / Excel / CSV**，打开文件快速出示字段。  
4. **Quality**：运行检测，展示抖动/模糊等结果 → 标记不合格 → 过滤前后数量对比。  

---

## E. 训练（3 min）

1. **Config**：选算法/版本/模型/超参/增强/GPU → 创建。  
2. **Runner**：Start → 日志 → Pause/Resume（若有）→ 展示指标上升。  
3. **Metrics**：曲线 + 导出报表；口播「指标来自 metrics 日志 / 训练进程」。  

---
