# 《现有系统功能盘点与差距矩阵》

> 产品基线：Orion Annotate（`vla-demo-antd`）  
> 目标产品：AI 多模态数据生产自动化工厂（AI Data Factory）  
> 分析日期：2026-11-09  
> 结论先行：**现有系统已具备招标 20 分四大业务模块的「可操作演示闭环」；作为第三套独立系统，核心差异化能力「AI 数据生产任务中心 + 可执行自动化流程编排」完全缺失；按「真实后端 / 真实算法 / 持久化 / 非模拟指标」标准，整体仍属前端 mock，工程真实性存在系统性缺口。**

---

## 1. 系统定位与技术栈

| 项 | 现状 | AI Data Factory 目标 |
|----|------|----------------------|
| 定位 | 国际 SaaS 风招标演示前端 | 以数据生产流水线为核心的自动化工厂 |
| 技术栈 | Vue3 + Vite + Ant Design Vue + Pinia + ECharts + xlsx + Vitest | 复用前端壳；新增 FastAPI + PostgreSQL + Redis + Celery + 算法 Worker |
| 端口 | `5102` | 保持前端 `5102`；后端建议 `8102` |
| 数据层 | `src/mock/*` 内存种子 + `businessDelay` | DB 持久化 + 对象存储 + 任务队列 |
| 权限 | 顶栏 Annotator / Reviewer / Admin 切换 | JWT + RBAC；保留演示三角色 |
| 品牌 | Orion Annotate / Orion Labs | AI Data Factory（ADF）/ 中英双语保留 Ant Design 人设 |
| 任务前缀 | `ORN-` / `ORN-JOB-` / `ORN-VLA-` / `ORN-EXP-` | 新增 `ADF-PROD-` / `ADF-WF-`；存量前缀可兼容迁移 |

设计文档明确非目标（现状）：真实模型服务 / 真实 GPU 集群 / monorepo 共享包。  
目标系统必须突破该边界。

## 5. 相对前两套系统的差异化缺口（必须补齐）

第三套系统的产品立意是「工厂 / 流水线 / 编排」，因此以下能力**不得弱化或用 QC Workflow 看板替代**：

| 能力 | 要求 | 现状 |
|------|------|------|
| 生产任务创建 | 数据来源/类型/目标数据集/流程模板/执行与审核人/优先级/完成条件 | 无 |
| 可视化工作流编辑器 | 16 类可执行节点 + 拖拽连线 + 条件分支 + 失败重试 + 版本 | 无 |
| 节点真实执行 | 导入/解析/抽帧/OCR/YOLO/NLP/分割/语音/点云/人工/质检/审核/VLA 结构化/导出/训练 | 无编排器 |
| 异步任务调度 | Celery/RQ，避免大文件与推理阻塞 Web | 仅前端 `businessDelay` |
| 任务执行监控 | 总量/执行中/等待/完成/失败/耗时/节点状态/重试/日志 | 无 |
| 28 个业务页面 | 见《03》 | 约 16 个业务页 + Home |

## 7. 盘点结论与下一步

- **演示路径**：现有 20 分四大模块可按菜单录屏；但无法证明「自动化工厂」。  
- **工程路径**：新增 Production / Workflow / Ops 三大中心 + 后端 + 算法 Worker；前端 service 替换为真实 API。  
- **文档路径**：本目录 02–15 为产品与工程设计基线；研发按《12-功能研发任务清单》P0→P1 推进。
