## 录屏提示

1. 每套单独开浏览器窗口，先停 2 秒在首页展示品牌差异。  
2. 按各项目 `docs/record-script-*.md` 顺序点操作；导出文件要在资源管理器里闪一下文件名。  
3. 切换角色时口头点出「当前是审核员/管理员」。  
4. 四套视频素材要求一致：真实可跑系统 + 脱敏样例 + 过程与结果出镜。
