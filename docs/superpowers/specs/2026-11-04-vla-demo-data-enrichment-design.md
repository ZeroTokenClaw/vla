## 1. 目标与边界

### 1.1 目标

在现有四套 Vue mock 演示上，把 QC / 预标注 / VLA / 训练 **四块一起加厚**，达到「偏生产感」体量，支撑更长、更真实的录屏与验收：

| 维度 | 要求 |
|------|------|
| 体量 | **每域 ≥50** 条可列表记录（任务 / 批次 / episode / 实验等核心实体） |
| 交互 | 列表具备 **分页**（`page` / `pageSize`）与 **筛选**（状态、模态、优先级、场景等） |
| 媒体 | **新生成**多套脱敏假媒体（图、短视频、音频），详情时长与字段对齐 |
| 厂商差异 | 四套 **各自独立编造**；字段名、枚举、部门 / 组织文案拉开；**不共用**同一 seed 文件 |
| 方案 | 方案 A：每应用独立 `src/mock/seed/*.js`（或等价路径）+ 服务层分页筛选接线 |

### 1.2 边界（不做）

- **不接**真实后端 / 数据库 / 对象存储。
- **不改**既有评分点功能范围（能力面保持；只加厚数据与列表交互）。
- 仍使用现有 Vue **mock 服务层**（内存数据 + 本地 URL）。
- 媒体仅为 **合成脱敏素材**（非真实客户 / 产线数据）。
- 工作继续落在分支 `feature/vla-four-vendor-demos`；本规格不要求改主分支策略。

## 2. 架构与数据流

### 2.1 Seed 生成器

每套应用各自维护：

```text
src/mock/seed/
  prng.js          # 固定 seed 的伪随机（可复现）
  qc.js
  prelabel.js
  vla.js
  train.js
  media-manifest.js  # 指向 public/samples 下本套媒体
```

（路径可用等价结构；关键是 **四套不共享同一 seed 源文件**。）

约束：

- 使用 **固定 PRNG seed**（每应用不同常数），刷新页面后记录集合可复现。
- 启动时由现有 `src/mock/*.js` 或服务初始化调用 seed，产出 ≥50 核心实体。
- Seed 失败时回退到 **最小可启动种子**（现有薄数据亦可），并在控制台记错误日志，避免白屏。

### 2.2 服务层与列表

- 各 `src/services/*`（或等价）统一支持查询参数：`page`、`pageSize`、以及域内 `filters`（对象或扁平字段）。
- 过滤在内存完成；返回 `{ items, total, page, pageSize }`（字段名可按厂商微调，但语义一致）。
- 列表页（QC / 预标注 / VLA / 训练）接上分页控件与筛选项；非法页码 **回落到第 1 页**；筛选无命中返回空列表（`total === 0`）。

### 2.3 媒体与详情

- 媒体落在各应用 `public/samples/`（文件名可相同，**内容哈希应不同**）。
- 详情、时间轴、播放器一律引用 **本地 URL**（如 `/samples/...`），不外链真实客户资源。
- **VLA**：为 episode 补齐轨迹 / 传感器 JSON（关节角、夹爪开合、时间戳等）。
- **训练**：补数据集目录、split / 版本钉扎、checkpoint 列表、验证表 / 混淆矩阵样例；训练日志加长。

### 2.4 异厂商字段策略

- 字段名与枚举 **故意不同**（异厂商感），但覆盖同一套演示能力（QC 流、Diff、episode 时间轴、训练曲线等）。
- ID 前缀保持：`DL` / `ORN` / `LM` / `SC`（及既有用户 id 前缀约定）。

数据流（概念）：

```text
seed(PRNG) → mock store → services(page/filters) → views(list/detail)
                ↘ media-manifest → public/samples/* → <img>/<video>/<audio>
```

## 3. 四域内容标准（每套各自满足）

### 3.1 QC（质检 / 多模态标注）

- 扩大任务池与样例池至 **≥50** 可列表任务（或任务 + 样例主列表之一明确 ≥50，另一侧同步加厚且可筛选）。
- 多模态状态齐全（标注中 / 审核中 / 终审 / 驳回 / 已分配 / 完成等既有状态）。
- 保留并加量 **故意错标** 与 **驳回链**（原因码、驳回人、时间）。
- 列表可按 **状态 / 模态 / 优先级**（及各厂商等价字段）筛选。

### 3.2 预标注（Prelabel）

- 文本批次与视觉批次加厚；文档 / 图片数量显著增加（支撑分页）。
- **保留故意错误 Diff**（错分类 / 错实体 / 错框等），供接受向导演示。
- 体现批次进度与抽检结果字段。

### 3.3 VLA

- **episode ≥50**。
- 每条（或抽样足够多条）附带关节 / 夹爪 / 时间戳 JSON。
- 多场景、多采集计划；问题单与时间轴对齐。
- **停止四套 / 多任务共用同一条 mp4**；按场景分配不同短视频（及配套图）。

### 3.4 训练（Train）

- 数据集目录 + split / 版本信息。
- **实验 ≥50**（覆盖 finished / ready / draft 等状态）。
- checkpoint、验证表、混淆矩阵样例。
- 训练日志加长（可分页或详情内滚动）。

### 3.5 媒体资产

- 每套独立生成脱敏图 / 短视频 / 音频若干套。
- `duration` / 帧数等详情字段与真实文件元信息对齐（避免 UI 写 12s 而文件 2s）。
- 缺失文件时 UI 显示占位，并打日志（见第 4 节）。

## 4. 厂商差异、错误处理与验收

### 4.1 厂商差异

| 应用 | 目录 | ID 前缀 | Seed |
|------|------|---------|------|
| 数联标注云 | `vla-demo-element` | `DL` | 独立 seed + 独立 PRNG 常数 |
| Orion Annotate | `vla-demo-antd` | `ORN` | 独立 |
| 灵眸 VLA Studio | `vla-demo-naive` | `LM` | 独立 |
| 星算训练台 | `vla-demo-arco` | `SC` | 独立 |

列配置、部门 / 组织维度文案继续品牌化，不回退成四套同文案。

### 4.2 错误处理

| 情况 | 行为 |
|------|------|
| 筛选无结果 | 返回空列表，`total = 0`，UI 空态 |
| 非法 / 越界页码 | 回落到第 1 页（或最近合法页，实现任选其一但测试锁定「非法 → 第 1 页」） |
| 媒体文件缺失 | 占位图 / 占位文案 + `console`（或现有 logger）警告 |
| Seed 抛错 | 回退最小可启动种子，应用仍可打开登录与基础页 |

### 4.3 验收

- **单测（每套 vitest）**：seed 核心实体数量 ≥50；分页与筛选行为；关键详情字段存在（VLA JSON、训练 checkpoint / val 表等）。
- **冒烟**：HTTP `5101`–`5104` 四套可启动可打开列表。
- **录屏脚本**：在既有 `docs/record-script-*.md`（及各套等价文档）中增补「厚数据」段落（翻页、筛选、打开含轨迹 / Diff / 验证表的详情）。
