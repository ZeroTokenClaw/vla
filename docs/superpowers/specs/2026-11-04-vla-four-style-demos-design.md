## 1. 目标

交付 **4 个功能完整、观感上像不同厂商出品** 的独立前端演示系统。功能覆盖全部评分点；视觉、文案、导航习惯、组件密度、空状态与术语体系刻意不一致，避免「同一套换主题色」。用脱敏但像真实业务的样例数据，在可运行环境中录制完整操作与结果。

非目标：真实模型服务 / 真实 GPU 集群 / monorepo 共享包。

## 2. 核心原则（本修订新增）

1. **异厂商感**：产品名、Logo 占位、登录后首页、菜单命名、按钮文案、表格空状态、帮助入口各自成套，评委不应一眼看出同源。  
2. **同功能不同叙事**：评分点能力都有，但模块名、流程叫法、页面节奏按「厂商人设」改写（见第 3 节）。  
3. **细节真实**：任务号、操作人、时间线、日志、权限差异、失败态、抽检比例、GPU 卡号、导出文件名等全部可点可看。  
4. **录屏友好**：每条得分点有固定演示脚本与可见中间态（进度、日志、状态流转）。

## 4. 功能范围（能力相同，呈现按人设）

### 4.1 多模态数据标注与质量控制（4 分）

1. 文本实体抽取、图像语义分割、语音切片、视频目标检测、点云分割（界面完整；点云可用预览图+蒙版结果，须标注类型与结果列表）。  
2. 任务创建、人员分配、状态流转、多人协作、批注、驳回返修、多级审核闭环（至少两级：初审/终审）。  
3. 抽检规则、随机抽检、标注规范页、合格通过、不合格驳回、合格回流。

### 4.2 自动化预标注（4 分）

1. 文本分类、实体识别、关系抽取、结构化 JSON 输出、人工修正。  
2. OCR、YOLO 框预标注、人工改框/改字。  
3. 确认 → 精标 → 质检 → 验收全流程页或向导。

### 4.3 VLA 智能数据采集与标注（8 分）

1. 采集任务、场景、方案、模式、动作模板、人员配置。  
2. 视频/图像/文本说明/任务指令联动；动作序列、关键节点、起止帧；导出 JSON / Excel / CSV（真实下载）。  
3. 抖动、遮挡、模糊、缺失、样本-任务不匹配检测；标记与过滤。

### 4.4 算法训练与验证（4 分）

1. 算法与版本、模型与超参、任务创建、GPU 分配（展示卡型号/显存占用 mock）。  
2. 启停控制、数据增强开关、loss/acc/mAP 曲线、结果与报表导出。

## 5. 页面与交互深化（更真实）

### 5.1 每套必备「像真系统」的零件

- 顶栏：产品名 Logo 字标、环境角标（演示）、当前用户与角色切换  
- 全局：操作时间线或审计日志（谁在何时做了什么）  
- 列表：分页、筛选、状态 Tag、批量操作至少一处  
- 表单：校验失败态、必填提示  
- 异步：300–1200ms 延迟 + 进度/骨架屏；长任务用「后台任务」可查看  
- 权限：标注员看不到终审通过；审核员可驳回；管理员可配规则与 GPU  

### 5.2 关键工作台（能力一致，布局随人设）

- **标注**：资源 | 画布/文本 | 标签面板；支持快捷提交与批注气泡  
- **协作**：看板或工单详情时间线；批注线程；驳回必填原因  
- **预标注**：三栏对照；Diff 高亮人工修改  
- **VLA**：任务头 + 视频时间轴（可拖拽打点）+ 指令/动作表；导出弹窗三格式  
- **质检**：规则编辑器（比例/模态/人员维度）+ 抽检结果 + 回流按钮  
- **训练**：实验配置 → 运行面板 → ECharts 曲线 → 导出报表（CSV/Excel）

### 5.3 样例数据真实感清单

- 任务 ID：`DL-2026-1104-0312` / `ORN-JOB-88421` / `LM-SESS-09A3` / `SC-EXP-20261104-17` 等分品牌前缀  
- 人员：真实中文姓名+角色；部分任务多人协作痕迹  
- 场景：家庭桌面抓取、工业料箱分拣、门厅开门等 VLA 常见场景文案  
- 媒体：`public/samples/` 下真实短视频/图片/音频（可脱敏）；点云用深度预览图  
- 指标：loss 曲线有下降趋势；mAP 合理区间；抽检不合格带具体原因枚举  
- 导出文件名含产品前缀与时间戳  

## 6. 工程约定

- 4 独立 Vue3+Vite+pnpm 项目；端口 5101–5104  
- mock：`src/mock/` + `src/services/` 延迟封装  
- 图表：ECharts；Excel：xlsx 或 sheetjs  
- **开发策略**：先做 DataLink（Element）为功能基准并录一条验收脚本；再分叉三套，**重做壳层（布局/文案/导航/主题）**，业务 store/mock 可复制后改 ID 前缀与文案，禁止只改 primary color  
- 每项目 README：启动方式、人设说明、评分点对照表、录屏脚本  

## 7. 录屏与验收

- 四套分别录；开场 3 秒内产品名与首页气质可区分  
- 按评分点脚本点完全流程；导出三文件各至少一次  
- 可见处理过程与结果；数据为脱敏样例
