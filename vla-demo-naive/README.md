# 灵眸 VLA Studio（vla-demo-naive）

Vue3 + Vite + **Naive UI（深色）** 演示前端，端口 **5103**。  
定位：机器人/具身智能创业团队风格的深色创作台，时间轴与会话优先；与数联、Orion 功能对等、厂商感不同。

## 启动

```bash
cd E:\omp\vla\vla-demo-naive
pnpm install
pnpm dev
```

浏览器：http://127.0.0.1:5103

侧栏为图标轨导航；底部 **Console / 操作流** 记录操作；顶栏可切换身份。

## 厂商差异（相对 DataLink / Orion）

| 维度 | 灵眸 VLA Studio |
|------|-----------------|
| 产品名 | 灵眸 VLA Studio / 灵眸智造 |

## 评分点 → 菜单路径 → 演示要点

| 评分项 | 分值 | 菜单路径 | 演示要点 |
|--------|------|----------|----------|
| 1.(1) 多模态能力 | 1.5 | 质控舱 → 标注工作台 | 五模态切换 + 真实样例 |
| 1.(2) 任务协作闭环 | 1.5 | 工单 → 协作看板 → 多级审核 | 创建/分配/流转/驳回 |
| 1.(3) 抽检回流 | 1.0 | 抽检回流 + 规范 | 规则、随机抽检、回流 |
| 2.(1) 文本预标 | 1.5 | 预标引擎 → 文本 | 分类/NER/关系/结构化 + 修正 |
| 2.(2) 视觉预标 | 1.0 | 预标引擎 → 视觉 | OCR + YOLO + 修正 |
| 2.(3) 验收全流程 | 1.5 | 预标引擎 → 验收 | 确认→标注→质检→验收 |
| 3.(1) 采集配置 | 2.5 | 采集台 → 采集配置 | 场景/方案/模式/模板/人员 |
| 3.(2) 标注与导出 | 3.0 | 时间轴标注 | 联动浏览 + 三格式导出 |
| 3.(3) 样本质检 | 2.5 | 样本质检 | 五类问题、标记过滤 |
| 4.(1) 训练配置 | 2.0 | 训练核 → 实验配置 | 算法/版本/GPU |
| 4.(2) 运行与指标 | 2.0 | 训练运行 + 指标 | 启停、曲线、报表 |
