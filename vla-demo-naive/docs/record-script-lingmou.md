# 灵眸 VLA Studio 录屏脚本（端口 5103）

产品气质：深色工作台 + 底部 Console；首页用「采集会话时间轴」。

## 开场（30s）
1. 打开 http://127.0.0.1:5103 ，展示图标轨与 Console。
2. 顶栏切换 标注员 / 审核员 / 管理员。
3. 首页点选 LM-SESS-* 会话进入采集台。

## 质控舱（约 3min）
1. 质控舱 → 标注工作台：五模态切换（文本/图像/语音/视频/点云）。
2. 协作看板：拖转或推进 创建→分配→标注→审核→回流。
3. 多级审核：批注、驳回返修、通过。
4. 抽检回流：配置规则、随机抽检、合格回流。

## 预标引擎（约 2.5min）
1. 文本预标：分类 / NER / 关系 → 结构化 → 人工修正。
2. 视觉 OCR + YOLO → 修正框。
3. 验收向导：确认→标注→质检→验收。

## 采集台（约 4min，重点）
1. 采集配置：场景、方案、模式、动作模板、人员。
2. 时间轴：联动浏览、关键帧、起止帧、动作片段。
3. 导出 JSON / Excel / CSV。
4. 样本质检：抖动/遮挡/模糊/缺失/不匹配 → 标记过滤。

## 训练核（约 2.5min）
1. 算法配置：版本、参数、GPU。
2. 训练运行：启动/暂停，看 loss/acc/mAP。
3. 指标面板导出 CSV/Excel 报表。

全程留意底部 Console 日志与 LM- 前缀任务号。
