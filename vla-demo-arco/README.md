# 星算训练台 StarCompute（Arco Design）

云厂商算法平台风演示系统：卡片仪表盘、算力池与训练实验优先。

## 启动

```bash
pnpm install
pnpm dev
# http://127.0.0.1:5104
```

## 人设

| 项 | 内容 |
|---|---|
| 产品 | 星算训练台 StarCompute |
| 厂商 | 星算云 |

## 评分点对照

| 评分点 | 菜单位置 | 演示要点 |
|---|---|---|
| 1.1 五模态标注 | 质控实验 → 标注工作台 | 文本/图像/语音/视频/点云 |
| 1.2 协作闭环 | 质控实验 → 协作看板 / 多级审核 | 分配、批注、驳回、初审终审 |
| 1.3 抽检回流 | 质控实验 → 抽检回流 / 标注规范 | 规则、随机抽检、通过/驳回、回流 |
| 2.1 文本预标 | 预标流水线 → 文本预标 | 分类/NER/关系/结构化+修正 |
| 2.2 视觉预标 | 预标流水线 → 视觉预标 | OCR + YOLO + 人工改框 |
| 2.3 验收向导 | 预标流水线 → 验收向导 | 确认→精标→质检→验收 |
| 3.1 采集配置 | 采集实验 → 采集配置 | 场景/方案/模式/模板/人员 |
| 3.2 时间轴标注导出 | 采集实验 → 时间轴标注 | 关键帧/动作序列；JSON/Excel/CSV |
| 3.3 样本质检 | 采集实验 → 样本质检 | 抖动/遮挡/模糊/缺失/不匹配 |
| 4.1 训练配置 | 训练实验 → 算法配置 | 版本/模型/超参/GPU 算力池 |
| 4.2 运行与指标 | 训练实验 → 训练运行 / 指标面板 | 启停、增强、loss/acc/mAP、报表导出 |
